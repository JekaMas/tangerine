# Owner decisions

The approval register contains no approved exception. Do not fill it from assumptions or generated reviewer identities.
An implementer can prepare a proposal, but only the owner can approve the exact change.
The schema defines the evidence fields. An object that passes the schema is not proof of an authentic owner decision.

The application must obtain the source statement from a trusted owner channel. It must compare the artifact and scope before use.
A changed artifact or wider use requires a new decision. A revoked or expired decision cannot authorize work.
Read `docs/change-control.md` before a proposed mock, fake, substitute, or added property.
