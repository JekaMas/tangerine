# Restricted inherited tests

The v5 tests contain constructed assessment inputs. This revision does not copy or execute those inputs.
The inventory retains the actual source paths, test names, and hashes. It does not grant permission to reuse them.

Each future mock, fake, test double, or artificial assessment case requires exact owner approval.
The approval must identify the case and use. A general testing instruction does not approve a substitute case.
Symbolic inspection of actual formulas uses no artificial teacher observation.
