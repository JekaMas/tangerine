# Design index

`docs/architecture.md` defines components and the two product flows.
`contracts/openapi.yaml` defines the internal operation inventory.
`docs/persistence.md` and `db/schema.sql` define the durable record architecture.
`docs/lifecycle.md` and `docs/runtime-and-storage.md` define state and failure behavior.
`docs/math-and-judgments.md` binds all formulas to exact populations and transport.
`docs/provider-contracts.md` defines stage inputs and provider boundaries.
`docs/audio-methods.md` defines synthesis, timing, and actual measurements.
`docs/sources/` defines data access, source preservation, and import semantics.
`docs/splits-and-validation.md` defines holdout and leakage rules.
`docs/maintenance-and-limits.md` and `docs/local-delivery.md` define local operation and recovery.
`docs/authority.md` identifies known approval and integration limits.

These are required design components of one full first release.
No partial implementation can declare full release completion.
