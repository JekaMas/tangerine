## Defects corrected during this consolidation

The final feedback model no longer receives or creates a server receipt field.
Its prompt names feedback-output.schema.json, not the server-enriched feedback contract.
The score transport now carries exact reduced fractions for the composite and all ratios.
The reference scorer preserves decimal-string exact arithmetic and does not derive another score from a display float.
Linguistic stages receive actual bounded taxonomy/context data, not only unusable version IDs.
Acoustic evidence separates a raw payload digest from the final subject audio digest.
Unit-level phone and prosody evidence must name the exact target unit, not merely another word in a shared utterance.
Retirement cannot clear an unresolved quarantine flag.
Expired-lease recovery and cancellation have explicit state transitions.
Local account/tenant assumptions were removed from active contracts and explanatory files.
