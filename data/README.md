# Local acquired source material

Native archives, full corpus files, private access correspondence and registration passwords are kept under this ignored data directory. They are not part of the Apache-2.0 software distribution. Preserve each source’s terms and notices. Public provenance, byte/hash receipts, native counts, acquisition failures and complete-release status are recorded in ../audit/corpus-acquisition-20261009/.

A .part file is incomplete. Ranged downloads preallocate .part files: their filesystem length is not downloaded progress. Completed verified ranges are recorded separately in .part.ranges.json. Native acquisition is separate from application import and normalization; no corpus content, script, macro or bundled program is executed in this research increment.
