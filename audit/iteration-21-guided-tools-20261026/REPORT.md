## Behavior and ownership

Reports can calculate an explicitly constructed example or reuse a saved report
population with its source selection and observation origins. Native arithmetic
and persistence remain authoritative. Experiment starters can save an authored
request or select a compatible saved generation dataset and configured profile.
The native owner freezes all actual references/configuration/current bundle.
Saving does not run a model. Judged/answer-checking and other existing workflows
remain available through Advanced; this guided increment does not invent a
semantic judge or independent gold.

`StarterForms` owns fields/options/submission construction; `useReports` owns
report/experiment delivery and selection; `reportRequest` translates failures
through the existing transient-read client. Pages render. `RecordPicker` reuses
the saved-list owner independently for both collections. One Cleanup session
owns selection, preview, confirmation, obsolete delivery and explicit apply;
`useCleanup` adapts its requests to the existing native API. No schema, database
migration, backend API or stored-data validation loop is added.
