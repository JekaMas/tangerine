Historical login/role/session, mandatory human approval, mandatory source/reference-audio-before-generation and archive-chain/revocation-epoch scaffolds are superseded by the current local/no-human-gate/single-admission contracts. Their old evidence remains historical; they are not current implementation requirements.

Azure TTS is an optional implemented adapter whose live resource/voice allowance remains unqualified here. Azure pronunciation assessment, hosted Whisper and OpenAI TTS catalogue candidates are preserved as provider bindings for other eligible installations; declaration is not an executed adapter or live entitlement. The current accepted diagnostic alternative is the explicitly selected native/local ASR/audio-capable route, not an invented Azure score. No hosted/paid qualification or purchased-credit fallback is authorized by this release task.
