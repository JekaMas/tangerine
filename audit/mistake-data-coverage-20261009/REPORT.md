## Mutation, diagnosis and matching

The owning contract is ../../specification/v2/docs/mistake-data-and-mutations.md. Every leaf's operator/procedure/context/evidence requirement is in ../../specification/v2/domain/mutation-recipes.v1.json. Text examples have explicit canonical-to-surface codepoint edits and round-trip checks. Acoustic recipes identify phoneme/prosody/pause/text routes or when a recording contrast is needed. They are authored procedures, not verified synthesis assets.

Generation first creates coherent canonical text, then localized typed changes under declared context. Existing mutation evidence stores a lossless provenance payload. LLM machine case review creates the actual contextual key from the final audio/evidence; the planned mutation does not prove what the provider produced. A text-only DeepSeek role uses actual source/acoustic measurements; it cannot directly hear audio. Separately configurable audio-capable checking can infer auditory judgments with its modality retained.

Answer checking freezes case/audio/context/key; the LLM maps original teacher assertions to localized events, stance/categories and required/forbidden repair/explanation propositions. Valid synonyms/new paraphrases are supported. Duplicate fragments count once; wrong category does not erase supported detection; repeated unlocalized quotations cannot earn several credits; genuine ambiguity/key defects use LLM adjudication/provisional results. Native code supplies all authoritative arithmetic. There is no human peer review prerequisite.

The catalogue makes abstract discourse/variant illustrations concrete and clarifies three stale illustration issues without deleting original examples: the auxiliary example's repair is simple past despite its old progressive context wording; the original across /s/ -> /sts/ adds two segments, while the supplemental single-insertion recipe uses /s/ -> /st/; the intonation illustration's “both contextual reviewers” is not a current human review requirement. All original examples remain authored and not empirically validated. No gap-free linguistic-quality claim follows from a static catalogue.

## Remaining data and work, with exact closure

1. **Per-leaf native crosswalk:** for every leaf, actual source/release/record/annotator, native span/interval/label, complete context, native-versus-LLM origin and supported exact project category. Retain unknowns. Closure is an inspected per-leaf count ledger, not broad-tag candidate lists.
2. **Final stimulus collection:** the full732distinct error/control stimuli under the existing six-per-leaf split policy, source/paired-family grouping, actual playback asset and machine/native labels. Authored examples and duplicate representations do not close it.
3. **Acoustic contrasts:** for each14segmental/12suprasegmental/9fluency leaf, actual matched wording/context, per-item contrast/bounds, sample clocks/alignments, final observed evidence and permitted control. SSML or requested IPA is not an observation. Recording import covers phenomena the sequential synthetic operator cannot realize precisely.
4. **Discourse/pragmatic/control event data:** full multi-turn context/roles/goals/variety, independent repair obligations and valid alternatives for10+8+8leaves. Native source classes and ASR transcripts are only candidate material until contextual conversion.
5. **Frequency/opportunity/relationship populations:** exact source/split/modalities/metadata, fully counted eligible events/windows and correct opportunities where an opportunity rate is wanted; independently localized pairs for co-occurrence and observed reference/prediction decisions for confusion. No universal frequency can be requested from a finite biased collection.
6. **Complete original external releases:** Cambridge R2 XML; both complete Shatz samples/workbooks; full Öksüz Cambridge paired/POS/error workbooks and each native dictionary/access scope; Doubao participant/instrument/coding/term package; independent Moodrick and NIR exports/dictionaries/terms. Outreach does not close them.
7. **Pending speech/source fidelity:** ICNALE separately linked monologue audio/dialogue video, Speak & Improve eligible full release, official L2 byte/count/version equivalence; optional full48kHzDRAL and its inaccessible third-party component remain separately recorded.
8. **Empirical application/model/teacher observations:** actual generation/checking runs, final audio behavior, independently labelled mapping/correction decisions and genuine teacher attempts for the established difficulty population. No substitute model-answer population or static count establishes human difficulty.
