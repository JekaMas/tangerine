# DEC-006: Prosody feature methods and units

Status: proposed; not approved. Owner approval reference: null.

## Affected paths

contracts/ground-truth.schema.json; contracts/evidence.schema.json; domain/prosody-methods.v1.yaml

## Existing dependency

See audit/open-decisions.json for the supplied finding and runtime rule. This proposal never creates an approval record or claims that the original property has been resolved.

## Proposed behavior

Require a feature-to-method registry with exact feature ID, measurement unit, extraction version, interval boundary, review conditions and uncertainty. Unsupported features require observed qualified human evidence. Azure en-US advisory scores cannot supply arbitrary acoustic measurements.

## Exact boundaries and remaining source dependency

The original feature and unit enumerations are missing, so no replacement enum is invented. Each entry must distinguish continuous measurement from a judgment, require audio/revision hashes and retain the interval. Missing/invalid pairs, unvoiced intervals, unreliable estimates and unsupported varieties must abstain or require human review; never produce invented numeric measurements.
