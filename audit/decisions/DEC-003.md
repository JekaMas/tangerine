# DEC-003: Versioned bilingual aliases

Status: proposed; not approved. Owner approval reference: null.

## Proposed behavior

A versioned registry contains taxonomy ID, language, exact alias, normalized alias and ambiguity disposition. Resolve only registered, unique aliases within the specified context. Preserve original quoted spelling and separate detection credit from category credit. Unknown or ambiguous terms require review for category credit.

## Exact boundaries and remaining source dependency

The exact alias entry set cannot be authored faithfully without all 122 original IDs and category definitions. Registry version is proposed as 1.0.0; normalization proposal is Unicode NFC plus Unicode case folding and trimmed surrounding whitespace, with no transliteration or fuzzy matching. No entries are fabricated in this project.
