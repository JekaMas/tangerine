Selected: self-hosted MLflow3.17.0 as an optional local prompt/context/trace/evaluation workspace. The user authorized research and specification updates; no application implementation, installation, Docker execution, inference, credential modification or publication occurred.

The owning specification is specification/v2/docs/llm-lab.md. RESEARCH.md compares the three primary-source options. ## What the future product supports

- Open Lab through the local helper; normal start and ordinary exercises work without it. All Lab data/telemetry stay local; content copies are opt-in.
- Edit/diff versioned prompts and JSON context policies for all nine existing stage/phase bindings. Export a complete immutable bundle, activate/revert it explicitly, and freeze each operation's binding. Historical scores/keys remain unchanged; cache reuse requires the same effective inputs.
- Inspect actual selected context components, hashes, budget, rendered request, initial reply, repair/fallback/transport attempts and normalized result. Preserve the existing blind-extraction/key-disclosure and input-fidelity rules.
- Trace Go/Python stages through OTLP/HTTP with native receipts, actual usage/latency and private sanitized artifact links. A stopped Lab never fails grading; explicit sync exports saved diagnostics without inference.
- Compare baseline/candidate prompt/context/model variants against frozen cases using the same actual native generation/evaluation/scoring owners. Preserve grouping/split/reference/scorer identity, explicit repetitions, failed/cancelled/not-run rows and configurable DeepSeek-compatible semantic judges.
- Report22separate diagnostic formulas for completion/projection/repair, canonical/mutation/request quality, length deviation, detection/category/repair/explanation quality, score differences, feedback grounding, actual acoustic confirmation, latency, token/cost totals, repeatability and leaf coverage. Original42learner/benchmark equations remain untouched. Missing observations stay N/A; self-consistency is not independent accuracy.
- Back up/restore consistent optional Lab data and native saved bundles/experiments; delete copied private bodies or report pending cleanup honestly. No human approval, automatic promotion or mandatory quality threshold is added.

Four new schemas define prompt bundles/selection input, per-attempt context snapshots, quality-case/expectation assets and experiment/variant/row/metric records. Five additive overlays update configuration/view, request, effective binding and receipts. Existing routes remain; helper actions are specified local tooling. Native exact arithmetic/storage/provenance stays authoritative, while MLflow metrics and artifacts are diagnostic copies.
