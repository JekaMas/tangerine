# Removed overengineering and preserved responsibilities

| Removed prerequisite | Current behavior |
|---|---|
| Two qualified human reviewers, attestations, third adjudicator | Configurable case_review/adjudication LLM stages; imported persons remain data |
| Per-property/per-example owner signature and expiry | Approved scope; labelled constructed deterministic tests permitted |
| Mandatory independent mapping audit | One mapper by default; optional diagnostic audit |
| Exact provider schema-keyword qualification and one JSON envelope only | Supported wire projection, harmless wrapper/additive-field normalization and same-profile JSON fallback |
| No output repair | One explicit output repair within deadline, preserving actual receipts/input |
| Exact-only wording/alias and novel-correction human review | LLM semantic equivalents against existing taxonomy/propositions |
| LLM enumeration of every whitespace codepoint | Server-derived coverage from real source spans |
| Full-source/732-case/100-participant benchmark release gate | All features/data retained as complete import/coverage/empirical reports, independent of local use |
| All voice/target canaries before first exercise | Exact requested combination reports; failures/unknowns remain visible quality observations |
| Human publication approval for otherwise playable audio | Use real playable case/machine key with quality warnings |
| Per-transfer grant dependency graph and permission epoch | Saved source-use setting, actual notices/agreement metadata and provenance |
| DefaultUSD10/dayUSD100/month and unknown-price approval per call | Optional disabled-by-default caps; honest unknown-cost display |
| Generic server reservation ceremony for record creation | Exact client-content DTOs; server assigns envelope/count/receipt fields |
| Signed list cursors/tamper-evident audit chain | Ordinary local pagination/audit; explicit local deletion remains possible |
| Treat reused synthetic voice as one genuine learner | Voice stratification; actual learner/source identities keep leakage edges |
| Reject all executable-looking archive members | Preserve all regular script/document bytes inert; never execute them |

Preserved: all122taxonomy leaves/examples, all42equations,11full-source identities,67internal operations, original native fields/annotators/scales, actual WAV/clock methods, immutable referenced answer/case/result history, feedback/disputes/benchmarks/recovery and configurable providers. Correct scorable references, exact arithmetic, actual bytes and secrets remain necessary product responsibilities, not approval/certification ceremonies.

The existing Next.js/Go/Python/PostgreSQL/private MinIO topology is retained behind one launcher to avoid a persistence rewrite. No hosted architecture, accounts, public API management, queue or human-review organization is added.
