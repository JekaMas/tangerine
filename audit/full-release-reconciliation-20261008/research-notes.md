# Primary-source research and limits — 2026-10-08

Research used source-owner/provider documentation, not simulator marketing as corpus evidence. No corpus files were acquired, no access application was submitted and no inference endpoint was called. Public counts are expected inventory values until reconciled against an actual authorized release.

## Provider protocol

[DeepSeek Responses API](https://api-docs.deepseek.com/api/create-response/) names deepseek-flash and deepseek-v4-pro; none/low/high/max effort, stateless history, structured text output, and an output cap including reasoning and visible tokens. Developer messages are treated as user input, so trusted instructions require the documented instructions/system route. These details support the configurable fast/low profile, not a successful live qualification.

[DeepSeek Responses guide](https://api-docs.deepseek.com/guides/responses_api/) defines compatibility rather than guaranteeing that a provider enforces every local cross-field invariant. Local validation, refusal/incomplete handling, payload capacity and exact stage projections remain necessary.

[OpenAI Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs?api-mode=responses) requires an object root without root anyOf, every property required, and closed objects. Nullable properties express optional values. The current guide limits properties, nesting and enum/string sizes; exact wire-schema binding still needs preflight checks and live qualification. [GPT-4.1 documentation](https://developers.openai.com/api/docs/models/gpt-4.1) lists the specified gpt-4.1-2025-04-14 snapshot and Structured Outputs support. A new reachable-output static walk found no open/optional objects or invalid root in the five unique model outputs, without qualifying wire size or provider behavior.

## Complete source inventories

[Cambridge EFCAMDAT](https://ef-lab.mmll.cam.ac.uk/EFCAMDAT.html) separately lists original XML, Shatz2020 cleaned data and Öksüz error-coded data. It reports 1,180,310 texts and 174,743 learners for R2 and requires approved academic access. The v2 registry therefore binds three distinct entries. Public descriptions do not supply private workbook dictionaries or actual use/transfer permissions. Other diagnostic models/collocation resources on that page are context, not a replacement for any listed required release.

[SpeechOcean762 author repository](https://github.com/jimbozhang/speechocean762) describes 5,000 utterances/250 speakers/five raters, original phoneme/word/sentence scales and pronunciation markers. Preserve every rater and aggregate separately. Approximate/unknown pronounced phones are not exact IPA. [OpenSLR 101](https://www.openslr.org/101) identifies the corpus release; an author Git revision is separately versioned. Actual native-member conformance and approved phone/taxonomy conversion remain unobserved.

[L2-ARCTIC owner](https://psi.engr.tamu.edu/l2-arctic-corpus/) and [v5 documentation](https://psi.engr.tamu.edu/l2-arctic-corpus-docs/) describe read speech and suitcase components, 24 read speakers and 22 suitcase speakers, 44.1-kHz audio, and manual versus automatic annotation. Preserve source substitution/deletion/addition markers and approximate/unknown phones. Manual labels and automatic alignment cannot become equivalent project gold. Actual bytes, source permissions and approved mapping remain separate prerequisites.

[BEA 2019 source site](https://www.cl.cam.ac.uk/research/nl/bea2019st/) lists W&I+LOCNESS 2.1 and FCE 2.1 separately and documents M2 source tokens, edit spans, annotator IDs and noop entries. Keep full available partitions, alternative annotators and corrections, including actual held-out annotation availability. A learner/essay count is not an M2 record count. Native ERRANT labels are candidate taxonomy mappings, not approved project leaf identities.

[NIR simulator](https://niracademy.com/nir-sim/) supplies public product context. It supplies no actual private annotated release/export/permission in the material reviewed. Moodrick public-page fetch timed out; the linked Doubao publication fetch failed. Those failures limit independent verification and do not prove that no private release exists. Moodrick and NIR remain separate blocked source entries. The reported Doubao study count is not an acquired record manifest.

## Speech and acoustic methods

[Azure short-audio REST](https://learn.microsoft.com/en-us/azure/ai-services/speech-service/rest-speech-to-text-short) documents PCM/mono request constraints, pronunciation assessment including the prosody option, and response timing/status fields. [Pronunciation assessment](https://learn.microsoft.com/en-us/azure/ai-services/speech-service/how-to-pronunciation-assessment) specifies feature/language limitations. This research does not qualify any configured resource, regional endpoint or voice. The service's shorter local cap remains a proposed bound; request credentials are private service data.

[Praat raw autocorrelation](https://praat.org/manual/Sound__To_Pitch__ac____.html) distinguishes the raw-ac algorithm from newer filtered-ac defaults and documents parameter ordering. This matters for FRC-016: recording a method name or a floating tool version does not define a reproducible measurement. Exact versions, commands, clock projection and reference/hypothesis tokenization still require a complete implementation binding.
