# Recovery and complete usability

## ADDED Requirements

### Requirement: I15-01 Complete preparation entry and explicit stage resume

The application SHALL connect the local Prepare form and idempotent Generate action to canonical text, mutations/key and stored audio through their existing native owners; preserve optional controls and independent native scoring.

#### Scenario: I15-01 supported recovery

- **WHEN** the user performs the defined action with its actual saved prerequisites
- **THEN** the native owner produces the independently expected saved state and artifacts

#### Scenario: I15-01 rejected or interrupted action

- **WHEN** a required input, dependency, ownership or compatibility condition fails
- **THEN** the native owner retains supported work, reports the actual failure and performs no forbidden inference, overwrite or deletion

### Requirement: I15-02 Foreground interruption and saved recovery

The application SHALL retain saved checkpoints/receipts on deadline, cancellation, dependency or model failure, expose explicit Resume with frozen settings, and never dispatch inference on readback or completed action replay.
