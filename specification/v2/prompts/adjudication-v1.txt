Review the saved key and the saved listener answer independently against the supplied canonical/surface text, authored mutation_manifest, public context, taxonomy and actual evidence. Previous machine assessments are claims under review, not a source of linguistic truth. Reconstruct each actual answer component's judgment before comparing it with the previous status; never accept a false assertion just because a previous assessor accepted it. Return the final semantic JSON, not a worklog or numeric grade.

Challenge the key and previous decisions with the supplied concrete correct controls. Permitted regional grammar, collocation alternatives, allophones, contextual connected speech, careful unblended speech and successful self-correction remain acceptable. Distinguish an explicit practice-target mismatch from a universal English error. Neither punctuation nor requested audio controls prove heard sound. A credible defective key uses the existing complete repair or insufficient-evidence result, preserving supported correction/detection independently of optional explanation judgments.

Source roles:
- canonical_text is correct intended wording before mutation; surface_text is the presented wording after mutation. corrections[].text and approved_text_alternatives are allowed repairs. The literal mutation_key.unit_repair_reference names these roles; ground_truth retains every obligation.
- answer and extraction contain the original listener response. Actual correction/rationale spans determine what the listener supplied. A replacement alone supplies no explanation.
- dispute_statement is a later challenge, not a replacement answer. A challenge can be wrong even when the saved answer and its assessment were right.
- prior_decisions and prior_assessor_note describe previous machine assessments. Their recorded statuses establish what was graded, but their explanations and judgments may be wrong. Do not invent prior rejection, listener wording or explanation from these notes.
- ground_truth.units contains the saved key, including rationale and rationale_required_propositions. A false statement in an answer or assessor note does not place that statement in the key.

Evaluate correction and optional explanation separately. Read the entire exact supplied explanation, including its quantifiers and scope. A true example cannot support an unrestricted universal assertion: for example, a correct irregular past form does not make "all English past forms take -ed" true. Do not silently narrow an explicit "all/every/always" statement to the current example. Judge that whole source-quoted statement unsupported when false, even if its opening example is correct. Conversely, interpret a contextual key obligation in its actual sentence/meaning/variety; do not invent a universal claim in it. Omitted explanations use supplied=false/not_supplied and have no penalty. False optional reasoning must not cancel a valid correction/detection.

Select the resolution from the actual defect:
- mapping_defect: the key is sound, but an answer component was assessed incorrectly. This includes a valid repair wrongly rejected OR a false optional explanation wrongly accepted. Return complete corrected evaluator decisions; key_repair=null.
- key_defect: an actual error, correction obligation or rationale/proposition in ground_truth is wrong or missing. Return the complete replacement key obligations. A false key rationale needs repair even if the listener's primary answer was correctly accepted.
- supported: the key and previous assessment are sound. A later wrong challenge does not invalidate an earlier correct acceptance.
- insufficient_evidence: supplied evidence cannot establish the requested change. Preserve supported findings and use decisions=null.
For contrast: a key claiming all past forms take -ed needs key_defect. A correct key with that false statement only in a listener explanation, previously accepted by an assessor, needs mapping_defect. A correct key that denies credit for that false explanation is doing its job.

For textual units, judge the text linguistically. Audible-target requirements limit recording confirmation; they do not prevent text review. No actual speech observation means inferred/unknown recording realization, not invented hearing and not automatically a defective textual key. Respect input_modality. Do not invent measured phones, private facts, permissions, people, human qualifications or blind review. Case-only review/disputes have no listener decisions.

Return llm-review-output.schema.json for llm-review-input.schema.json. Root fields: schema_version, resolution, unit_judgments, decisions, issues, reason, key_repair. Include exactly one unit_judgments entry per actual ground_truth.units ID, including unchanged units and controls. State the actual defective source field or assessment in reason.

Answer decisions use the complete evaluator-output object (schema_version=1.0.0) for saved claims and actual unit/option/proposition IDs. Reevaluate every affected correction/explanation field, including copied additional_assertions: each actual supplied explanation needs its exact source quote, supported/unsupported/unknown judgment and contextual reason. A statement rejected as false must not retain a supported assertion label. A required proposition not met is absent from satisfied_proposition_ids; violated_proposition_ids contains actual forbidden IDs only. Keep the valid independent counterpart. Correction definitions in the key do not contain an answer's accepted/rejected status.

For key_defect, produce complete key_repair with unchanged base_case_sha256/audio_sha256, all proposed_units, actual affected_components, reason and total same/added/removed/split/merge correspondence_relations. Preserve the heard text/audio, valid correction options, controls and unrelated obligations. Copy retained correction objects completely, including approved_text_alternatives even when empty; do not omit fields while copying them.

A rationale repair must supply BOTH a correct contextual rationale AND actual corrected rationale_required_propositions. Every proposed unit with explanation_eligible=true requires at least one correct rationale_required_propositions entry: replace a false proposition; do not erase the list. Explain why the canonical/approved form fixes the surface form, rather than claiming the erroneous surface form is correct. Replace every affected false required/forbidden rationale proposition, including copied ones. A worklog such as "removed the false rule" is not the replacement rule. Correction and rationale proposition IDs have separate scopes: preserve a sound correction proposition while replacing a false rationale proposition even if both IDs are p1.

Use proposal-local new: references for genuinely new semantic IDs; the server assigns persistent envelopes. affected_components names detection, correction, classification, explanation or key as applicable. Supply complete supported saved-answer decisions for the revised units when available; otherwise use decisions=null and the app maps that same saved answer. Other resolutions use key_repair=null. Code calculates the authoritative scores from these semantic judgments; do not output invented grades.
