# Tangerine active specification

This is the current specification for the existing implement-teacher-error-trainer OpenSpec change. It is not implemented application behavior. Current user authority is ../../docs/authority.md. Immutable imported archives remain under ../../spec-inputs. Earlier root contracts and audit reports are historical; this namespace is the sole active contract set.

The main flow is topic/speaker count/word length, optional level/broad mistake categories -> saved clean LLM text -> novel mutations and their list/key -> local or service synthesis -> stored playback -> free-text listener answer -> LLM comparison with the list -> exact score and recommendations. docs/simple-generation-flow.md and contracts/exercise-request.schema.json own this flow. Reference audio, full corpus acquisition, empirical frequency tables and separate case review are optional enrichment/evaluation, not prerequisites.

The product is a simple local open-source GitHub project: download a source ZIP or clone, supply provider keys, start it, use it. No accounts, roles, public API setup, human peer review, review credentials, required repeat audits or corpus-wide certification precede ordinary use. LLMs check answers, review generated cases and resolve disputes; native code calculates exact grades. Six original LLM functions are preserved; generation has clean-text and mutation phases, case_review is optional and adjudication is a configurable stage. Mapping audit remains an optional diagnostic.

All 122 original taxonomy IDs and examples, 27 core and 15 auxiliary equations, all internal operation IDs, all original data fields and all eleven source identities remain preserved. Person/qualification/approval fields are legacy imported metadata, never runtime prerequisites. SpeechOcean762, L2-ARCTIC, W&I+LOCNESS, FCE, EFCAMDAT R2, Shatz2020, Öksüz2025, Doubao study records, Moodrick, NIR and original project gold remain full-source features.
