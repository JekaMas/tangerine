# Frozen Lab inputs, judges and diagnostic arithmetic

This completes llm-lab.md without additional services, required reviews, threshold gates or public API routes.

## Dataset and variant identity

llm-quality-dataset.schema.json is the dataset asset: ordered full llm-quality-case records, one declared scope, optional stage/phase selector for stage scope and dataset_sha256 over UTF-8 JCS excluding its own digest. The experiment digest equals this saved dataset digest. Cases may name several leaves; case ID is unique. Each input/expectation asset is stored with its original byte hash before running. Stage input uses that stage's input schema. For answer_pipeline, input obeys the dataset's answer_pipeline_input definition: fixed ground truth/audio version, exact answer UTF-8 asset/hash and frozen task components. generation_pipeline/full_flow use exercise-request.schema.json or blueprint-write.schema.json; their different generated contents remain explicit. Mapping/score accuracy metrics apply only to fixed-reference event correspondence. A generation/full-flow case without that correspondence reports those metrics N/A and uses its generation/semantic quality predicates. No candidate output rewrites a reference asset or key during comparison; key reconsideration is a separately identified run/reference version.

Each variant contains configuration_asset_id plus configuration_sha256, resolving to a complete frozen configuration record, and its saved bundle. Profile_id and judge_profile_id must resolve inside that snapshot. Source/speech/price/model parameters and stage overrides come from that snapshot, not mutable settings. Credential references resolve locally at call time; secret values are neither frozen into assets nor hashed. Missing keys produce failed rows with preserved inputs. The experiment's judge_policy_asset_id/hash resolves to the exact prompt, rubric and input/output schema identities; null means no semantic judge. Save every actual effective binding and judge receipt. No new prompt is inserted into the original nine application bindings.

Allocate exactly dataset cases × variants × repetitions planned rows, one unique (case_id,variant_id,repetition) tuple, in dataset order, variant order, repetition order. Repetition indices start at1. A row is complete only when its selected scope and requested scorers finish; a semantic unknown metric does not fail an otherwise completed call. A provider/scorer failure is failed with retained partial outputs; cancellation marks the active row cancelled and remaining unstarted rows not_run. All planned tuples remain in completion/failure denominators. The batch records progress after each existing foreground operation and needs no background scheduler.

## Semantic judge contract

llm-quality-judge-input/output schemas and prompts/lab-judge-v1.txt define the diagnostic judge. The experiment saves a policy asset containing that prompt's exact text, its SHA-256, rubric version/text and the actual judge schema byte hashes. The selected configured linguistic_audit-capable profile runs this dedicated diagnostic call through the same provider adapter, deadline/accounting/receipt owner. It does not send Lab propositions into the ordinary linguistic-audit output contract.

Input contains the case/reference origin, saved scope/context, candidate output asset/body and explicit propositions with reference receipts. The output gives exactly one supported/unsupported/unknown verdict per requested proposition, a reason and candidate-output evidence pointers; unknown has an explicit missing-evidence reason. Evidence references resolve into supplied actual assets; JSON uses RFC6901 pointers and text uses cp:start:end half-open Unicode-codepoint locators with an exact existing slice. No numeric grade is accepted. Diagnostic code translates verdicts into the registered sufficient statistics; it cannot turn an unknown acoustic observation into a correct phone. Actual judge prompt/binding/receipt is saved with the row. Judging against that candidate's own labels remains self_consistency, including when a different model reads those labels. Independent_llm requires a separately saved reference call uninfluenced by the candidate output under test; authored/native references retain their real origins. All semantic verdicts are model judgments, not automatic scientific gold.

## Context and trace completeness

Stage snapshots include the complete selected stage DTO. In addition to the existing kinds, candidate, extraction, scoring_result and rubric identify those otherwise omitted inputs. Mapping/mapping_audit receive saved extraction. Feedback receives actual native scoring_result. Diagnostic judge snapshots identify candidate/rubric/reference material with actual hashes. Component ordering cannot omit required DTO fields; repeated parts are referenced once with their owning DTO, never secretly dropped. Null/omitted optional components have reasons.

mapping_audit is independent of the first mapper: its component list has no prior_decisions. Feedback/adjudication may receive prior decisions. The whole exact wire request remains the authoritative reconstruction asset. Supplied evidence is data; trusted prompt/recipe/context policy remain owned instructions. A locally edited policy cannot leak keys/prior results into the blind extraction stage.

Save bundle IDs/version metadata separately from their actual content hashes. Validate the nine distinct manifest stage/phase pairs and matching context-policy stage/phase when importing a bundle; registry_export numeric versions resolve their actual text/policy, builtin registry metadata is null. Template variables are literal named root stage-input fields: substitute their JSON-encoded values using a single nonrecursive pass, with no dotted expression evaluation, environment lookup or executable template engine. Field omission is a preparation error. Hash template bytes before substitution and actual wire bytes afterward. Bundle storage survives Lab removal.

Each logical stage cap covers its initial call, structured-output fallback, transport attempts and semantic repair together; it never restarts per attempt. Export may use at most min(1000ms, remaining time after the original five-second persistence reserve); if no budget remains, mark unexported without delaying the result. Enabling body capture without trace export retains sanitized local assets and reports disabled export. Disabled Lab creates no successful export claim. Export-status diagnostics live in operation diagnostics, not by overwriting immutable receipts; explicit sync appends an export outcome. No persistent retry queue is introduced.

## Aggregation and comparisons

Metric observations retain unreduced sufficient_statistics keyed by the named registry formula variables. numerator/denominator are exact arithmetic inputs, not reduced fractions that lose population size. known_subtotal is a decimal string for known token/cost components when the total is unknown; otherwise null. Unknown totals use insufficient_data, value=null and a missing reason, even when the known subtotal is zero. An observed nonterminating ratio has its exact numerator/denominator and may have value=null without being missing.

Pool raw counts for completion/projection/repair/canonical-preservation/mutation-consistency/request-fulfilment/detection/category/repair/explanation/feedback/acoustic rates. In particular pool TP,FP,FN and recompute F1; do not pool reduced F1 denominators or average per-case percentages. Word-length relative deviation and score MAE are equal-weight means of applicable row observations; record canonical and surface deviations under separate sufficient-statistic keys and use surface for the named aggregate. Latency quantiles concatenate actual attempt durations (failed calls included, cache views excluded) then apply the existing nearest-rank rule. Tokens/cost sum actual receipts, preserving unknowns and known subtotals. Jaccard averages all unordered completed repetition pairs within the same case/variant; freeze event correspondence for generation outputs or return insufficient_data when events cannot be aligned. Macro leaf recall first pools per-leaf TP/FN, then averages the observed error-leaf recalls; all missing/control leaves remain in coverage reports.

The comparison asset is an ordered array of objects with baseline_variant_id, candidate_variant_id, metric_id, paired_row_keys, excluded_row_keys/reasons, baseline_value, candidate_value and candidate_minus_baseline, represented as exact rational objects (decimal-string numerator/positive denominator) or null with reason. For pooled metrics, recompute each variant over the common applicable tuple population then subtract; for mean metrics, average per-tuple deltas; for quantiles, compare the named quantiles on that common population. Completion/failure reports also use each full planned population. A changed scope/dataset/reference/scorer cannot enter the same paired report. Polarity means the named behavior should succeed/fail, not that a negative teacher assertion must always receive zero. Reference applicability comes from the frozen typed expectations, not candidate optimism. These diagnostics supplement all original42formulas.

Development run/surface/snapshot evidence extends these contracts through ai-development.md and the ai-development-run/ai-surface-inventory schemas. It does not weaken frozen reference identities or native arithmetic.

Freeze scoring_policy_version=answer-components-v2 for new ordinary comparisons. Explanation presence/credit/unknowns are independent observations even when the legacy task flag is false. Preserve GE/TE/EA and unknown EK/EQ; do not exclude unresolved supplied reasons. Primary score comparisons cannot penalize omission or reason-only issues. Historical composite policies are separate reference populations.
