# Complete local flows

Start: download/extract the source, copy the sample configuration, supply keys required for selected actions, run the helper and open the local page. The library is empty until actual import or generation. Startup neither buys inference nor downloads corpora. Missing optional keys appear beside affected actions.

Prepare: enter topic, number of speakers and approximate text length; optionally select English level and broad mistake categories. Advanced blueprint fields remain available. One Generate exercise action saves clean LLM text, applies novel category mutations and saves their list/key, then synthesizes local or service audio and stores the exercise. Source excerpts, measurements and a separate LLM case review are optional. See simple-generation-flow.md for exact input expansion and phase contracts. The operator can play/use a valid case immediately with any explicit quality warnings. There is no reviewer-person form or certification milestone. Failed synthesis retains candidate and failure; retry uses a real call.

Listen/answer: select a playable library case, freeze case/audio identity, show public context and audio, accept an English/Russian free-text answer, save draft and submit. Save exact submitted bytes before inference. LLM extraction/mapping check the answer; native code computes exact metrics and LLM feedback explains them and recommends targeted practice with clearly labelled new examples. Results show supported decisions, N/A populations and genuinely unresolved interpretations. Reconsider is an LLM action. Optional diagnostic audit is explicit. Closing/reopening reads saved data without a call.

Review: inspect machine review observations, correspondences, rationales and evidence status. Rerun through a selected configurable LLM profile when requested. Existing native human annotations are visible as source data. No competence attestation, peer approval or independent human listening step exists.

Results/disputes: show all result revisions. A user supplies a dispute statement; LLM adjudication compares it with the frozen answer/key/evidence. Append any supported revised mapping/score/key/correspondence without rewriting original history. An inconclusive/refused operation retains the original and offers retry or clearly marked provisional status.

Sources: show all eleven full-source entries with expected components, actual inventory/counts, native/raw semantic status and missing operational inputs. Import a complete local archive/folder/export; optionally use a genuinely documented vendor adapter. Preserve all source fields, scores, annotators, scripts as inert bytes, derivatives and native partitions. Raw ingestion can complete while some semantics are unbound. Review warnings and inspect rejected/quarantined records; no raw-only record disappears. Full-source status is separate from normal product usability.

Benchmarks: generate/import the full122-leaf collection, split by genuine identity/provenance, evaluate all42metrics and mapping/correction/audio/repeatability reports. Label population origin; native human and LLM labels remain distinguishable. Missing gold/participants/provider observations produce insufficient_data. Benchmarks do not block new local exercises.

Settings: choose default LLM profile, stage overrides, feedback language, speech settings, source paths and optional limits. Keep credentials in local secret references and display presence only. Backup/restore/cleanup use a concrete local plan and preserve previous workspace on failure. All error views retain user input and explain the actual failed action. Operation creation fields follow operation-ownership.yaml; the UI never invents server receipts.

LLM Lab: Settings shows the active saved prompt/context bundle and diff, local trace/content-capture settings and an Open Lab link. The optional local UI edits versions and compares explicit experiment runs. Native helper actions export/activate bundles and run fixed-case comparisons; edit/activation never regrades saved attempts. Capture is opt-in and all failed/unperformed rows remain visible. See llm-lab.md.

Result component display: show correction correctness/credit separately from optional explanation. No explanation shows not provided and N/A without penalty. A supplied explanation shows supported/unsupported/unknown assertions, separate applicable score and feedback. Explanation-only unresolved status leaves the primary grade visible. New task explanation flags invite reasons but never require them.
