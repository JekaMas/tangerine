# Complete local activity flow draft

The top-level views are Library, Prepare, Review and Results, with local Settings and Sources reachable as ordinary activity forms. They share one workspace and require no sign-in or role switch. The operator can inspect authoring separately; pre-submit and blind projections prevent accidental disclosure, not adversarial isolation from the computer owner.

Library calls list_cases with safe pagination. A source/setup/rights problem appears as its actual status, never an invented example exercise. Selecting an eligible published case starts a frozen attempt and presents teacher-start-view plus opaque audio route. The teacher reads the public context, listens and writes an English/Russian answer. Playback events are descriptive client evidence. Draft save retains exact text. Submit freezes the original answer before any model call. Saved/evaluating views show actual operation state without score or key. Complete results show exact ratios and grounded requested-language feedback; review_required shows issues with null final aggregates; evaluation_failed retains the answer and offers only eligible explicit retry. Closing/reopening the page reads the saved attempt/result without making a paid call. Cancellation revokes the evaluation fence. Key disclosure is a separate post-submit action under the pending GAP-002 policy.

Prepare exposes every blueprint field using blueprint-write validation: task/context/components, speakers, CEFR/L1 requests, variety/register, target taxonomy leaves, rendering constraints, turns and intended source use. Defaults are only the declared configuration defaults. Changing a blueprint creates a version. Generate saves the request/binding/source selection and actual provider candidate. The operator reviews candidate and advisory linguistic audit, explicitly accepts a draft case and writes its key/render plan. Render and Measure retain final bytes and missing/failing observations. A failed hard constraint or unsupported target stays visible and blocks progress. Revised content creates a child version; it cannot reuse parent approvals. Publication is offered only after current rights, all measured/human gates and two independent final approvals. Quarantine/retire show their exact consequences and require current revision; no hidden forced transition exists.

Review identifies a real person and competence/conflicts using local evidence forms, without an account. Select the exact case/audio review context. The blind-review-view presents public context/constraints and an empty blind observation form matching blind-annotation. Save the independent record before the Disclose key action. A later note is post-key evidence, never an edit of the blind record. Reviewers map actual observations to units, mark unplanned defects, inspect permitted corrections and supply final decisions. Disagreements retain both original records; third-person adjudication cannot replace the two final approvals. Invalid identity, prior exposure, missing competence, wrong audio or incomplete key keeps the case unpublished.

Results lists actual attempts and immutable result revisions. Inspecting a result performs no model call. A dispute captures original answer, case/result/audio, claimed issue and actual supporting evidence. Review/adjudication follows the separate recorded workflow; changed keys create new versions and same-audio unit correspondence. The operator explicitly selects attempts for synchronous reconsideration; no background batch silently changes history. The newest complete reviewed revision is shown with original result accessible, and quarantine/rights/evidence-unavailable warnings remain.

Sources lists all eleven full-source entries even when unavailable. For each entry the operator supplies exact authorized release files/manifests, native format binding, parser/transformation and applicable use/transfer grants. Inspect/import accounts for every release member/record and preserves originals, accepted/quarantined/rejected counts and split metadata. Unknown/private fields stay unbound, not guessed. Vendor settings accept actual credential/adapter/documentation references only. Partial or failed import cannot claim full acquisition. No startup download or sample substitution occurs.

Settings selects explicit LLM profile and requested feedback language, key presence/secret references, operation-dependent speech settings, intended use and local limits. Unknown settings fail with declared safe field errors. Saved configuration changes invalidate affected caches without changing history. Backup/restore/deletion display the exact plan and counts/hashes; a confirmation applies only to that plan. Startup/stop preserve data and stored playback does not depend on cloud budget. Operation/error rendering uses fixed domain/error-codes.yaml code plus safe English message; the UI keeps input on failure and offers only an eligible explicit retry. Unsupported/unauthorized operations remain disabled with their true blocker.

All create/submit forms use the eventual exact client DTO; FRC-006 remains the unresolved request/server/source field split. These written flows do not certify browser behavior, human identity, provider calls or full data acquisition.
