# Controlled acoustic rendering

Iteration 8 extends the existing foreground speech owner. It uses the saved LLM edits; it never asks another model to invent, approve or repair an acoustic control. Original categories, source scopes and providers remain unchanged.

A local request permitting pronunciation/fluency mutations selects `kokoro-controlled-v1` before its preparation is saved, including an unrestricted family selection. Explicit profiles stay selected. The complete initially resolved profile is saved in `preparation-settings.speech_profile`, separately from the accepted configuration and its unchanged digest. Plain text-only or explicit zero-mutation requests retain the plain local adapter. The Settings model list reports the installed controlled model, voices and Praat controller availability; the existing Kokoro setup command supplies the same model assets.

The Go plan projects each accepted edit/category onto its original utterance and freezes literal text, scope, voice and requested pace. Python's pure compiler binds complete target words/phrases to the G2P tokens of a complete source phrase, preserving verbatim text including spaces. A word-level edit never splits surrounding context into separately synthesized clips: doing so would insert unplanned phrase-boundary silences. It rejects unresolvable partial-word targets and conflicting overlaps before synthesis. Phone/stop replacement precedes duration/pitch, then pause, then gain. A combined duration/pitch/gain intent compiles to distinct stages so gain follows inserted pauses. Disjoint internal phone targets remain distinct. Compatible controllers share a scope and preserve every unit/repair obligation.

Kokoro retains exact framed token IDs, predicted durations, word/G2P association and upstream timestamp projection. Complete source-phrase audio, native timing and complete paired-phrase replacement audio are private durable assets before native resolution. Resolution writes an immutable `acoustic-production-plan` child and checkpoints its identity before transformation. Native VOT release/onset/F0/pulse proposals are saved in the child's optional `landmarks`; transforms reuse that proposal. An interrupted transform reuses both the accepted source and that same child. Completed child response recovery uses the existing operation/receipt owner. No stored model/audio/manifest is revalidated during reuse.

Each transform has its own accepted source/result assets, actual native receipt, private observation and sample correspondence. The current decoder timing proposal is carried through the actual transformation clock map. Exact inserted pause intervals survive later gain and remain separate from unwanted silence. The final sample-map asset follows `audio-sample-map`; assembly quality/pace observations use the separate `render-progress.diagnostic_asset_id`. Intermediate maps/production children remain in each piece's `acoustic_state.completed_steps`. The final key uses saved `unit_intervals` from actual target timing carried through every transform, rather than the whole phrase or character-proportional offsets. A phone pair changes only its target interval: the replacement is cropped from the complete altered phrase using its own actual decoder timing; the paired full recording and its original digest/clock remain private. Outside samples are copied exactly except the declared in-target fades. Compatible edits sharing a scope retain composed phone differences and the altered target timing. Perceived IPA, stress, accent and lexical correctness stay unknown without the corresponding observation; a production command is not a perceptual judgment.

Waveform controllers are implemented in the private Python speech process: pinned Praat overlap-add for vowel/pitch/duration, exact 24kHz silence, measured release/periodicity-based VOT editing and explicit gain. Native numerical F0/formant/landmark measurements are separate from the transform owner. The complete defined equations and splice policies remain in `full-build-contract.md` and `audio-methods.md`. Quality warnings stay advisory. Missing timing/landmarks retain a named failed operation/source/key; they do not become a confirmed error or a silently substituted phone.

An explicitly configured Azure F0 profile can use its whole-phrase IPA for paired clips, plus native whole-piece pitch/duration and boundary pauses. Internal word/phone targeting, arbitrary fine timing and VOT are unavailable on this REST adapter and fail before source dispatch, with the controlled local route remaining selectable. This capability distinction does not remove any category or provider. Hosted tests prove request/response adaptation only; account entitlement, actual hosted audio and allowance require their actual observations. Paid calls remain forbidden without personal per-case approval.

The listener projection exposes only selected profile, completed/total pieces, first unfinished piece and ready-to-assemble state; it never exposes source/reference clips, decoder context or the answer key. A complete set of pieces still needs successful assembly before playback becomes available. Historical preparations have 0/0 counters and remain readable. The same stored playback route serves the final WAV.

Development acceptance retains literal independent numerical cases, actual generated clips and decoder/landmark qualifications, private HTTP input/output, durable storage/key/playback observations and MLflow copies. Those checks belong to development; no repeated user-facing certification or peer-review gate is introduced.

Safe progress counters and the selected speech profile ID are materialized in the preparation's PostgreSQL checkpoint, in the same CAS as its private progress head. Public Library reads need no MinIO request. This is a projection of the saved stage, not a readiness audit. VOT landmarks explicitly identify their source-interval-relative24kHz clock and source offset; whole-piece sample correspondence remains absolute. A newly transformed WAV is admitted once; accepted stored assets are trusted on resume.

Every native dispatch/context snapshot retains its real preparation/case, piece/execution and frozen plan/manifest references. A transform's running/source/resolved-plan checkpoint commits before dispatch. The stored safe projection uses `selected_speech_profile` and `first_unfinished_piece` as metadata, projecting them to the public DTO's ID-named fields; these metadata values are not extra graph entities or media-readiness dependencies.

New acoustic core plans declare their actual required IPA/prosody/timed-pause capabilities in stable order. Existing private `/plan` and `/piece` callers remain compatible, with `/resolve` and `/transform` owned by the same worker. The broader internal whole-source render operation, source integration and auditory/scoring owners retain their separate full-product contracts; this increment claims the on-demand preparation path and its actual controlled render stages.

Settings offers an explicit controlled-Kokoro selection as well as automatic initial selection for acoustic targets. Both use the same one-time Kokoro model setup. Changing Settings affects new preparations; existing text, controls, voices and model bindings remain frozen. The native third-party controller binding is praat-parselmouth0.4.7/Praat6.1.38; its upstream GPLv3 terms and source are retained separately from Tangerine's Apache-2.0 source licence: https://github.com/YannickJadoul/Parselmouth and the pinned PyPI source distribution recorded in requirements locks. No restricted corpus is bundled by this feature.

The source-derived pitch-range recipe is admissible on its exact registered acoustic leaf with empty explicit pitch cues: its real median and target points do not exist until its source audio is generated. Mutation admission preserves that intent for native resolution. The same empty cue on an unrelated category or text-only unit remains invalid. This repairs the cross-layer route without adding another model call.

Explicit complete-scope reference phones enter the G2P token association before upstream empty-phone filtering and capacity splitting. This preserves literal targets such as `$` without interpreting embedded text markup or synthesizing context fragments. The target's original surface spelling remains unchanged in the saved request and key.
