# Answer interpretation runtime

Iteration10 owns semantic interpretation of a submitted answer. Exact arithmetic, completed numeric scores and final recommendation/feedback generation retain their subsequent iteration owners. A semantic result is never labelled a completed numeric grade.

The existing submit operation commits the original answer and language before invoking checking. Its foreground child interprets that immutable answer using the case/audio, task components, configuration, model profiles and prompt bundle saved when the attempt started. Changing Settings does not change an attempt's retry. The existing `:retry` operation supplies the frozen answer/configuration identities and expected attempt revision; reads and history never invoke inference.

Blind extraction receives the unchanged answer, requested language, task components, neutral public context and all122 taxonomy IDs/labels. Definitions and inclusion/exclusion rules belong to mapping, rather than blind source-location work. It receives no canonical/surface text, mutation key or first decisions. Optional `source_tokens` are server-derived whitespace token boundaries in original Unicode codepoints, retaining punctuation and exact quoted text. They contain no diagnosis or hidden key. The complete original answer is retained; no required answer or taxonomy member is truncated.

Extraction admission resolves exact codepoint coordinates, an exactly matching UTF16 coordinate or a unique original quote. Ambiguous repeated quotes remain unresolved/repairable; coordinates never justify inventing text. The source claim contains its component quotes. The server assigns `clm_` plus32hex characters from SHA256 of JCS `[answer_sha256,start_cp,end_cp,exact_text]`, sorts by original source position, derives complete disjoint coverage and retains unparsed substantive spans. Explicit backwards retractions, contained attachments and duplicates preserve original members; omitted substantive text uses the existing bounded output repair. Competing interpretations of the same exact source span retain all raw clauses under one source identity and a conflict marker; mapping cannot select one as certain. Undeclared overlaps remain invalid. Reads/retries trust admitted outputs instead of rechecking their schemas or hashes.

Mapping receives the saved clean and mutated utterances, authored units/options/rationale propositions, all122 category IDs/labels, full definitions/rules for authored targets and answer-mentioned aliases, and aliases for the actual answer language(s), actual available same-case evidence, unchanged answer and admitted extraction. The typed mapping-input.listener_components carries canonical claim IDs and verbatim listener repair/reason quotes, so the complete typed input is self-contained. The extraction context also retains full source locations and grouping; raw extraction local references remain local. Provider/render receipts are not linguistic observations or proof that a requested sound occurred. Existing typed observations keep their actual subject and modality; absent acoustic observations remain absent. The immutable resource snapshot retains the complete definitions and English/Russian alias registry. The deterministic per-stage projection always retains every category identity; it includes English aliases plus Russian aliases when requested or present in the answer. This source selection is recorded before dispatch, never a fallback that silently drops context to fit a budget.

One admitted decision is retained per canonical claim. An omitted/null/empty-object/empty-array component can receive its fixed not_supplied envelope only when frozen extraction confirms source absence; real supplied content and meaningful contradictory fields never receive defaults. This normalization precedes the one combined schema/source admission. Semantic reference admission checks target/category/option/proposition/evidence scope once. Supplied correction and explanation flags follow actual source components. Reasons are optional, and a supplied reason is always assessed independently of task.explanation. False or unknown reasoning cannot cancel supported detection or repair. Supported/unsupported/unknown additional assertions retain exact original quotes. Missing rubrics or novel unresolved corrections never become automatic perfect credit. A definite model rejection can retain option_id=null when no valid repair matches; it remains rejected with native zero credit, while positive/partial credit still needs a valid rubric and genuine uncertainty remains unresolved. No model supplies a fraction or authoritative score.

Compatible claims for the same event/stance retain all members and their earliest representative. Compatible components combine; contradictory unretracted repairs, classifications or stances remain explicit component issues. Duplicate suppression cannot discard new substantive findings or choose a favorable alternative. These groups are saved for the later native scorer. Optional mapping audit is a separate call over the same frozen source/extraction/key, without first-mapper output. Prose-only differences are harmless; actual semantic differences or unavailable audit remain diagnostic, preserving supported primary findings.

PostgreSQL owns a single foreground lease with token, epoch, expected revision and deadline. No transaction spans model or media work. Linked accepted resource/extraction/mapping/audit assets and private immutable interpretation-checkpoint documents supply durable resume. Explicit retry reuses completed admitted stages, sharing one additional transient transport attempt across the request. Stage limits remain40s extraction and70s mapping/audit, inside270s plus the persistence reserve. The browser allows310s, proxy300s and API285s. One repair and supported structured fallback use their existing stage deadline; no silent model/billing fallback exists.

Every publish compares the real lease owner/revision/epoch/deadline. Late outputs may remain provider diagnostics but cannot enter the reusable checkpoint. Cancellation/failure retains the answer and accepted prior stages, clears the owned lease and records evaluation_failed. A dead process leaves expiry for explicit retry. Dependency loss can save an existing error-response document in PostgreSQL without MinIO; it must not imply that the already committed answer was unsaved. Small interpretation JSON writes have a five-second storage timeout inside the foreground deadline. A stale owner cannot overwrite its replacement.

The closed post-submission result-envelope optionally includes interpretation-view: source claims, target/category and independent correction/explanation statuses, contextual notes, issues and audit state. It excludes raw provider/context/binding/asset/credential identities. Successful semantic interpretation returns saved with no fabricated score. Genuine selected-component uncertainty returns review_required for subsequent LLM resolution, never mandatory human review. Browser refresh reopens findings; checking failure offers explicit retry while keeping the submitted answer read-only.

Private stage observations retain actual input/context, frozen bindings, wire requests/responses, receipt identities, output repair and failure lineage. MLflow export is required development evidence for actual selected model tests and remains optional to ordinary app use. Constructed protocol fixtures prove controller behavior; only explicitly actual local-model cases establish their observed linguistic outputs. No purchased credits, hosted API, overage, borrowed authentication or cloud-model fallback is authorized.
