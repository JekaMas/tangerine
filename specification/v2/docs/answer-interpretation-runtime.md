# Answer interpretation runtime

Iteration10 owns semantic interpretation of a submitted answer. Exact arithmetic, completed numeric scores and final recommendation/feedback generation retain their subsequent iteration owners. A semantic result is never labelled a completed numeric grade.

The existing submit operation commits the original answer and language before invoking checking. Its foreground child interprets that immutable answer using the case/audio, task components, configuration, model profiles and prompt bundle saved when the attempt started. Changing Settings does not change an attempt's retry. The existing `:retry` operation supplies the frozen answer/configuration identities and expected attempt revision; reads and history never invoke inference.

Blind extraction receives the unchanged answer, requested language, task components, neutral public context and all122 taxonomy IDs/labels. Definitions and inclusion/exclusion rules belong to mapping, rather than blind source-location work. It receives no canonical/surface text, mutation key or first decisions. Optional `source_tokens` are server-derived whitespace token boundaries in original Unicode codepoints, retaining punctuation and exact quoted text. They contain no diagnosis or hidden key. The complete original answer is retained; no required answer or taxonomy member is truncated.

Extraction admission resolves exact codepoint coordinates, an exactly matching UTF16 coordinate or a unique original quote. At valid explicit codepoint coordinates, omitted or restyled double quotation marks in a duplicate model quote are representational: project the exact original source slice, keeping all its quotation marks. Apostrophes, other punctuation, words and negation cannot change; invalid coordinates and ambiguous location searches receive no guessed source. Raw provider wording remains in diagnostics. A unique complete-word occurrence can resolve a quote also present inside a longer word; two complete-word occurrences cannot. Ambiguous repeated quotes remain unresolved/repairable; coordinates never justify inventing text. The source claim contains its component quotes. The server assigns `clm_` plus32hex characters from SHA256 of JCS `[answer_sha256,start_cp,end_cp,exact_text]`, sorts by original source position, derives complete disjoint coverage and retains unparsed substantive spans. Explicit backwards retractions, contained attachments and duplicates preserve original members; attachment components are projected only after retractions are resolved, so withdrawn correction/category/explanation wording remains in original source history but is absent from its parent assessment; omitted substantive text uses the existing bounded output repair. Competing interpretations of the same exact source span retain all raw clauses under one source identity and a conflict marker; mapping cannot select one as certain. Undeclared overlaps remain invalid. Reads/retries trust admitted outputs instead of rechecking their schemas or hashes.

Mapping receives the saved clean and mutated utterances, authored units/options/rationale propositions, all122 category IDs/labels, full definitions/rules for authored targets and actual supplied category-label aliases, and aliases for the actual answer language(s), actual available same-case evidence, unchanged answer and admitted extraction. The typed mapping-input.listener_components carries canonical claim IDs and verbatim listener repair/reason quotes, so the complete typed input is self-contained. The extraction context also retains full source locations and grouping; raw extraction local references remain local. Provider/render receipts are not linguistic observations or proof that a requested sound occurred. Existing typed observations keep their actual subject and modality; absent acoustic observations remain absent. The immutable resource snapshot retains the complete definitions and English/Russian alias registry. The deterministic per-stage projection always retains every category identity; when actual category-label spans are supplied, it includes English aliases plus Russian aliases when requested or present in the answer. When no category is named, alias_entries is empty because classification wording has no consumer; full authored-target definitions and all122 identities remain, and the complete dictionaries stay frozen in resources. This is deterministic relevance selection, not budget truncation. This source selection is recorded before dispatch, never a fallback that silently drops context to fit a budget.

One admitted decision is retained per canonical claim. For explicitly normalized interpretation calls, a complete JSON value missing only trailing container punctuation can be closed before the single admission; incomplete strings/values are never invented and the raw wire remains unchanged. Known-target detection labels follow frozen source stance and target truth, while genuine model uncertainty stays unresolved. Assertion judgments follow their admitted source component, including correcting a misplaced or duplicated explanation assertion without erasing a valid repair; quotes crossing distinct components remain repairable. If a correction rejection was supported only by a misplaced explanation finding, the existing bounded repair independently reassesses the actual proposal instead of silently assigning zero. The mapped extraction context carries typed target_references with short local refs and exact canonical unit IDs. These stable per-call refs skip real-ID collisions and are resolved before admission/persistence; no undeclared or sole-target fallback exists. Unknown target IDs remain invalid, with exact frozen target/rubric/source guidance in the existing bounded repair. Missing/null optional note prose becomes an empty note without spending the model repair; existing meaningful values stay intact. Unsolicited model categories are removed when no listener category span exists, preserving supported components without classification credit. An omitted/null/empty-object/empty-array component can receive its fixed not_supplied envelope only when frozen extraction confirms source absence; Otherwise empty components with supplied=false may discard irrelevant status/uncertainty labels when source confirms absence; the raw labels remain in provider diagnostics. Real supplied text, supplied=true, non-null options, proposition/evidence IDs or substantive assertions never receive absence defaults. This normalization precedes the one combined schema/source admission. Semantic reference admission checks target/category/option/proposition/evidence scope once. Supplied correction and explanation flags follow actual source components. Reasons are optional, and a supplied reason is always assessed independently of task.explanation. False or unknown reasoning cannot cancel supported detection or repair. Supported/unsupported/unknown additional assertions retain exact original quotes. A contextual quote wholly inside the source claim can be narrowed to the single complete component it contains, provided it does not cross the other component; the original provider quote remains in diagnostics. Every supplied explanation retains at least one source-quoted judgment with a contextual reason, including assertions also covered by rubric IDs, or explicit uncertainty. A rubric match alone cannot stand in for assessing the entire reason and its scope; an absent source assessment triggers the existing bounded repair. Missing rubrics or novel unresolved corrections never become automatic perfect credit. A definite model rejection can retain option_id=null when no valid repair matches; it remains rejected with native zero credit, while positive/partial credit still needs a valid rubric and genuine uncertainty remains unresolved. An omitted correction option can be joined only when the supplied scoped proposition IDs identify exactly one existing option; ambiguous joins are repaired without guessing. A claimed positive correction or explanation with no required rubric findings requests the existing bounded repair, even when it contains source-level supported assertions; such assertions do not substitute for actual scoped proposition findings. It never silently becomes rejected/zero, receives invented credit, or becomes a novel alternative merely because the model omitted those IDs. Definite supported rejection and genuine uncertainty keep their existing behavior. Unmet required conditions are not forbidden proposition IDs; repair feedback includes the actual scoped rubric. No model supplies a fraction or authoritative score.

Compatible claims for the same event/stance retain all members and their earliest representative. Group membership includes original attached clauses, including withdrawn attachments retained as source history; attached/withdrawn decisions never become additional scored assertions. Compatible components combine; contradictory unretracted repairs, classifications or stances remain explicit component issues. Duplicate suppression cannot discard new substantive findings or choose a favorable alternative. These groups are saved for the later native scorer. Optional mapping audit is a separate call over the same frozen source/extraction/key, without first-mapper output. Prose-only differences, assertion array ordering and repeated copies of the same source/judgment tuple are harmless; actual semantic differences or unavailable audit remain diagnostic, preserving supported primary findings.

PostgreSQL owns a single foreground lease with token, epoch, expected revision and deadline. No transaction spans model or media work. Linked accepted resource/extraction/mapping/audit assets and private immutable interpretation-checkpoint documents supply durable resume. Explicit retry reuses completed admitted stages, sharing one additional transient transport attempt across the request. Stage limits remain40s extraction and70s mapping/audit, inside270s plus the persistence reserve. The browser allows310s, proxy300s and API285s. One repair and supported structured fallback use their existing stage deadline; no silent model/billing fallback exists.

Every publish compares the real lease owner/revision/epoch/deadline. Late outputs may remain provider diagnostics but cannot enter the reusable checkpoint. Cancellation/failure retains the answer and accepted prior stages, clears the owned lease and records evaluation_failed. A dead process leaves expiry for explicit retry. Dependency loss can save an existing error-response document in PostgreSQL without MinIO; it must not imply that the already committed answer was unsaved. Small interpretation JSON writes have a five-second storage timeout inside the foreground deadline. A stale owner cannot overwrite its replacement.

The closed post-submission result-envelope optionally includes interpretation-view: source claims, target/category and independent correction/explanation statuses, contextual notes, issues and audit state. It excludes raw provider/context/binding/asset/credential identities. Successful semantic interpretation returns saved with no fabricated score. Genuine selected-component uncertainty returns review_required for subsequent LLM resolution, never mandatory human review. Browser refresh reopens findings; checking failure offers explicit retry while keeping the submitted answer read-only.

Private stage observations retain actual input/context, frozen bindings, wire requests/responses, receipt identities, output repair and failure lineage. MLflow export is required development evidence for actual selected model tests and remains optional to ordinary app use. Constructed protocol fixtures prove controller behavior; only explicitly actual local-model cases establish their observed linguistic outputs. No purchased credits, hosted API, overage, borrowed authentication or cloud-model fallback is authorized.
