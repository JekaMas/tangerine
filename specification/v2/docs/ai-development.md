# AI development through the local Lab

The actual user requires Tangerine AI development to use the selected MLflow tooling and have no unaccounted prompts/context in its owned execution paths. This is the project development contract. Ordinary downloaded application use still needs no Lab, benchmark, human review or quality threshold. This specification update starts no service, makes no model call and grants no implementation authority.

## Mandatory development route

An AI-affecting change is any change to a model-call owner, adapter/request serializer, trusted instruction/schema description, prompt/context template, recipe selection, source retrieval/context selection, tokenizer/budget, model/profile parameters, speech model/voice/render input, extraction/mapping/judge/scorer interpretation, cache identity, retry/repair behavior or diagnostic exporter. Review the actual dependency diff; filenames alone are not the oracle. A documentation-only edit that changes no execution contract, or unrelated CSS, need not run inference. Every AI-affecting increment records its affected properties and known surfaces, frozen baseline/candidate identities, selected positive/negative cases and observed Lab evidence in the existing canonical change. Development completion cannot claim AI integration/quality with an absent or incomplete observation record.

Before future authorized model execution, use `sh scripts/tangerine lab` and existing export/activate/eval/sync helpers. A development run explicitly enables native tracing and sanitized content capture for its selected permitted data. This is a run-scoped overlay, never a silent change to ordinary workspace capture settings. Prompts may be edited as normal; manual activation is retained and has no pass threshold or human approval. Record actual activation and use, not just a registry screenshot. Freeze exported numeric/local content versions and the effective configuration before executing.

Lab availability is required to declare this development evidence synchronized, not to calculate a learner grade. If Lab goes down during a run, retain native actual inputs/results/receipts, mark missing exports and continue independent repair/inspection. Explicit sync only exports retained artifacts. Until every selected observation is synchronized and linked, the development record is incomplete. A zero-call deterministic change uses its actual Lab experiment artifacts and records zero expected calls with a reason; do not buy inference to fill an irrelevant stage. Pure specification exploration keeps future behavior not_run and does not claim this runtime development route was exercised.

## Every trusted instruction and context item has an owner

Control trusted fragments at their actual origin: stage prompt, context instruction, schema descriptions/wire-schema projection, repair/fallback wrappers, judge rubric, speech/ASR reference policy and adapter-supplied role/frame defaults. Version them by exact source/configuration hash and save the rendered role/order/parameters. The original nine prompts remain; supplemental fragment bindings do not erase or duplicate them. Dynamic values, source material, topic/answer text, examples and validation-error details are data, even when inserted into an owned repair template. Do not recursively evaluate them as instructions.

A per-call snapshot records the actual prompt/context policies and all source/recipe/key/answer/evidence/previous-result selections plus explicit omitted components/reasons. For speech it records SSML/literal text, selected voice/model/locale/operations, audio/chunk/ReferenceText and original/final clocks as applicable. Provider/local SDK defaults that affect the model are saved as explicit effective parameters; unknown provider-internal context or model weights remain unknown. Never claim control over hidden hosted training/context behavior.

Serialize the exact noncredential request after all projection/default/repair construction and before dispatch. Persist that model-visible artifact and its actual SHA-256; identify each input part with trust class, byte range/asset/hash and modality. Credential transport headers/secret endpoint parameters are separate and absent from artifacts. Binary audio is referenced by exact bytes/hash; multipart framing/field names/order/content types are preserved separately, without copying secrets. For locally hosted models, retain actual tokenizer/G2P/token/phoneme preprocessing outputs and model/voice-weight/configuration digests plus executable/library versions, not just the public pipeline arguments. An opaque local preprocessing path is an explicit inspection limit until instrumented; it cannot count as a complete model-visible snapshot. A later SDK mutation requires a new snapshot matching actual transport bytes. Prompt/context hashes alone are insufficient when runtime concatenation adds words. Empty/no-prompt policy and omitted optional parameters are explicit, not fabricated strings. Snapshot preparation failure makes no model call; preserve its preparation diagnostic.

Stage-specific disclosure remains: blind extraction sees no key/expected labels/prior score; independent mapping audit sees no first-map decisions; mapping uses frozen key/extraction; feedback uses actual native scores. Unconditioned Whisper has prompt=null; Azure assessment receives actual surface ReferenceText, not canonical corrections. Dataset source personal fields stay out of ordinary prompt data. Context budgets cover all instructions/schema/frames/reserved output; selection preserves original required content and records its omissions. Changing a trusted fragment, model-visible input or effective parameter changes the appropriate binding/cache identity.

## Reconcile planned work, actual inference and exported evidence

ai-development-run.schema.json records the change, actual dependency hashes, inventory, baseline/candidate experiment IDs, affected surface/property/case IDs, actual input snapshots/receipts/trace/span links, MLflow run IDs/artifact references and coverage discrepancies. Its top-level MLflow run/artifact references include actual deterministic zero-call artifacts; these may not be omitted just because observations is empty. LLM/judge execution snapshots require the existing llm-context-snapshot link; non-LLM inputs use the typed execution_snapshot definition with actual speech/model inputs. A run is observed only with a nonempty selected property/case scope, resolved inventory/dependencies, actual native/Lab artifact identities and no unresolved required coverage discrepancies. Preparation-failed/cache records have no dispatch observation; a crash after an initiated call retains its independently observed dispatch. It uses existing private documents/assets; no new service or public endpoint is required. Each actual attempt, including refused/incomplete/transport-error/late/cancelled/local execution, has its own observation. A cache view references the original execution, has zero new dispatches and is labelled inspection. A repaired/fallback attempt records its real changed request, parent attempt and reason. Explicit sync cannot increase provider/local dispatch counts.

Completeness uses a three-way join: independent dispatch observations from the tested transport/local model boundary, native snapshots/receipts, and actual MLflow exports. Preserve every unmatched item with a reason. Report orphan dispatches, missing requests/replies, duplicate links, unresolved bindings, unexercised required paths and failed export. For a controlled test, the boundary observer is independent of the exporter/receipt writer; copying the receipt count into expected_dispatches is not an oracle. Actual remote tests may use real request IDs/boundary evidence; local model tests observe the actual inference entrypoint. A process crash leaves a prepared dispatch without an outcome until recovered; it does not erase a possible charged request.

Dispatch completeness, snapshot completeness and exported completeness are matched/observed counts over the declared finite selected populations. Zero denominator is N/A and cannot prove coverage. Observed includes initiated attempts even if they failed. Disabled/unimplemented/irrelevant surfaces are separately reported and cannot be used to claim all surfaces exercised. The run's status is incomplete if any required selected observation or proof is absent; native learner results remain valid under their existing rules. No universal coverage claim follows from a zero-call foundation or a passing search/manifest check.

## Artifact fidelity and maintenance

Development artifacts are private/local by default. Full trusted text and permitted source/answer bodies are inspectable through actual private assets and sanitized Lab copies. Redaction records the original-reference and redacted-byte hashes separately plus the redaction method/field reasons. A missing or wholly redacted required component is a visible inspection limit, never 'full context captured'. Test secret removal with controlled canaries, preserving original grading bytes. Source permissions still govern whether a body can be copied; when forbidden, preserve permitted metadata/private local reference and explicitly report that Lab body inspection is unavailable.

Backup/restore/deletion includes these native run/inventory/observation artifacts and copied Lab artifacts under existing maintenance rules. Copy failure is pending, not successful deletion. No queue, distributed registry, accounts, signatures, recurring benchmark or external telemetry is added. The canonical tasks and property graph retain incomplete integration as blocked. The current code foundation has no implemented provider/synthesis owner; this policy specifies their future acceptance and does not certify zero blind spots today.
