# Self-contained generated texts

Ordinary generation must not produce exercises whose scored mistakes depend on private generator facts, an external document/story, undisclosed relationships, intended meanings or special rules the listener was never given. The generated dialogue/monologue must carry the facts needed to diagnose its own contextual mistakes in its audible surface text. public_context remains the neutral topic and already displayed general task/variety settings; it is not a new channel for hidden scenario answers or a separate briefing workflow.

All 122 categories/recipes remain available. Context-sensitive discourse/pragmatic/variety categories use self-contained audible instances. For example, I am Dr Lee; please call me Dr Lee followed later by Good morning, mate can establish the address preference in the dialogue itself. Good morning, mate on its own must not be generated as an error on the basis of a private address preference. Accent/dialect is not a mistake without the existing publicly stated task basis and actual phenomenon evidence.

The canonical generator knows the selected targets and creates clean text that supports their later mutation. The mutator preserves that text and chooses placements whose decisive facts remain audible after the mutation. A recipe's written contextual assumption is a generation instruction to instantiate the needed facts, not a fact the scorer may silently assume about the listener. Do not copy a contextual illustration into a standalone exercise if its private note is necessary for diagnosis. Select another self-contained instance/placement within the requested category rather than discard categories or expose the answer key.

If a specific saved clean script offers no valid placement for a requested exact target, retain it and report the existing constraint_unsatisfied condition with an actionable new-text choice. A broad-family request can choose another feasible leaf in that same family. New text is explicit and follows the persisted preparation/version flow; no unlimited hidden regeneration loop or new human/quality gate. The generation prompts carry this rule, so ordinary generation selects self-contained text directly.

Mapping, optional explanation assessment and LLM reconsideration use only the heard/saved surface text, neutral disclosed settings and actual evidence. A private intended-context note cannot make a learner correction or explanation wrong. The clean canonical text identifies the mutation intent but does not disclose facts that are absent from the stimulus; diagnostic correctness is judged against the actual self-contained surface. Imported corpora/exercises remain preserved with their actual original contexts and disclosures; this restriction is on newly generated ordinary texts, not deletion of source data or taxonomy.
