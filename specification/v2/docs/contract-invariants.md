# Canonical semantic invariants

Canonical persisted records use the bundled closed JSON schemas. Provider replies pass through the tolerant projection in provider-contracts.md; wire additive fields/wrappers are not rejected as storage fields. A source raw tree retains all unknown native fields. No parser executes source code or spreadsheet formulas.

Preserve exact submitted answer bytes, original codepoint spans, audio bytes and versioned key/metric identities. Server-derived IDs/times/hashes are not required in creation requests; operation-ownership.yaml supplies exact projections. References used in scoring must resolve to the selected case. Unknown semantic labels remain raw or provisional, not fabricated evidence.

Missing measurements are null with method/status/reason, never zero or a successful observation. Requested phonemes and scalar pronunciation scores are not observed IPA. LLM review evidence is model inference unless supported by actual measurements/native annotations. No human peer review or qualification is required.

An immutable saved case/key/result is revised by appending a new version. Exact arithmetic uses the preserved27core/15auxiliary formulas, with zero-denominator N/A and half-up display only at presentation. Detection, category correctness and repair/explanation are separate. Unknown category spelling or a valid novel correction cannot erase an otherwise supported detection. Optional audits and benchmark shortfalls are reports, not normal-use gates.

A genuine unresolved scoring decision remains provisional with issue and LLM reconsideration. A formatting wrapper, missing optional audit, unpaid benchmark or absent unrelated corpus is not semantic uncertainty. State changes, operation deduplication, actual bytes and secret-safe projections protect ordinary local correctness, without grant graphs, signature ceremonies or certification startup gates.
