# Optional saved-audio diagnostics

The ordinary user cycle remains topic → LLM clean text → separate LLM mutations/key → actual speech → listening/answer → LLM interpretation and native scores/recommendations. Diagnostics are an explicit optional action on the current Review screen. No corpus, reference recording, peer reviewer, Lab or diagnostic completion is a prerequisite.

The Go API owns saved case/source-use selection, frozen configuration and prompt asset, foreground operation, private assets, native receipts/Lab copy, new-result admission and final transaction. Python owns actual WAV derivatives/clips, native measurement, independent transcription and actual auditory inference. The web owns only selection, saved readback and actionable failures. No new database table, account, service or queue is introduced.

The current routes and complete response DTOs are audio-diagnostics-runtime.openapi.yaml; domain/audio-diagnostics-runtime-operations.json maps the original speech_measure logical operation. POST /api/v1/cases/{id}/measurements accepts the unchanged measure-request: exact case, saved final audio digest and registered method IDs. The API expands that DTO into audio-diagnostic-packet for private speech:8090/internal/v1/measure. It never sends an answer, first mapper decision or prior acoustic observations to the auditory model. Methods are ffmpeg-ebur128-v1, praat-ac-v1, faster-whisper-local-en-v1, qwen25-omni-audio-v1 and gemini-audio-v1.

GET defaults only returns selections/setup instructions. Explicit Settings writes materialize the built-in text/plain prompt as a private asset and store its identity. Existing profile fields omitted by a later Settings write retain their saved value; explicit null disables the audio judge. Selecting a profile does not dispatch, install or download. Original Qwen Omni7B remains the written default; an explicitly selected pinned3B non-commercial research model is a separate local option. Model terms remain separate from the Apache-2.0 software. Gemini requires an explicitly eligible free/included profile and configured key; no paid fallback is permitted.

Each explicit measurement operation freezes the input/key/manifest/configuration before dispatch, saves every actual expanded packet/clip and response, and retains native receipt/context assets and method versions. A typed audio-diagnostic-run references its input/output/support assets, receipts and typed audio-measurement records. Completion publishes its operation result transactionally. Failed partial work remains failed with raw evidence and any independently admitted earlier rows. Replaying the same idempotency key reads that saved result and performs no new work; a new user action creates a new run. Saved reads trust admitted database and asset data rather than rehashing/requalifying it.

Native Praat uses all declared parameters, including very_accurate=true. Each selected protected feature is an observed numeric value or explicit unavailable/null result with its reason; lexical stress/rhythm/boundaries cannot be inferred from pitch alone. Independent Whisper accepts only the actual16kHz derivative, fixedCPU/int8 model/parameters and no reference conditioning; consume the whole segment iterator and preserve exact text, timestamps/probabilities and parameters. Only afterwards compare its hypothesis to the frozen surface text with lexical-v1 S/D/I and exact WER fraction.

Auditory target clips use actual24kHz half-open intervals, one second of available context and a maximum10seconds. The packet includes only overlapping planned units, exact relevant acoustic intent and public context. The mutation key states intent, not observed confirmation. An existing canonical acoustic source piece is supplied as separately labelled reference only if all selected units belong to its single utterance and the complete actual source fits one clip; otherwise reference remains null. Longer/multi-piece references are not guessed or silently truncated. All supplied derivatives and exact processor/template/token/tensor context belong to the actual call. Audio-judge findings remain model inferences, with supported/contradicted/uncertain/not_applicable labels and optional proposed IPA; they are not native calibrated pronunciation scores.

Mixed clips retain every unit's requested prosody features and the exact matching acoustic_edits controller names. A unit with neither uses speech_realization. The Go input and Python measurement projection use that same existing unit/plan association; temporal controls do not need a fabricated prosody entry. Each auditory measurement retains target_unit_id and the exact actually supplied auditory_finding, including description, reason and inferred IPA, so optional review and the UI can associate the report with the correct mutation. Missing requested unit/features produce explicit not_measurable/null rows with reason model_omitted_target; those native unknown rows contain no fabricated auditory_finding. The original model output remains unchanged. This needs no extra model call, mandatory re-review or completion gate; an actual-model qualification must separately observe a nonempty genuine model finding rather than count these unknown placeholders as model answers.

GET saved measurements is case-scoped,20rows with an after UUID cursor; it performs no inference. Optional review freezes all already admitted reports for its exact selected case in the separate measurements input. These are not native Evidence IDs, do not mutate the ground truth and do not make a text reviewer a direct listener. Primary scores remain unchanged until the existing explicit component-scoped reconsideration/adjudication flow establishes a supported revision. Backup and reference-aware erasure include the run, owned measurement documents and private artifacts; copied Lab cleanup retains its existing explicit status.

The local Qwen auditory adapter uses the checkpoint’s Qwen2_5OmniThinkerForConditionalGeneration for text diagnostics. Its processor receives the actual already decoded mono PCM derivatives in target/reference order; there is no second generic URL/image/video decoder or speech-output decoder. Capture names the actual model class, encoded samples/template/IDs, generate call and raw output. The saved original checkpoint identity and selected3B/7B profile remain unchanged; this route produces no voice/audio output.

Omni's processor forces max_length audio padding. Set that length to the longest supplied derivative rounded up to a complete feature hop and set truncation=False. Both target/reference clips retain all actual samples, including a partial final hop; do not pad short selected clips to the checkpoint's five-minute default. Capture the actual processor audio options and complete encoded arrays. This changes neither the selected clips nor the270s foreground budget.

Local auditory profiles explicitly select compute_type=float32 or int8_dynamic. Omission keeps a frozen legacy binding at float32. The built-in3B CPU choice selects int8_dynamic: PyTorch quantize_dynamic converts Linear weights to qint8 in place; embeddings/convolutions/other layers remain float32. The original7B profile remains available. Save compute_type in the frozen configuration, and record actual module count, quantization engine, PyTorch version and input/output. This is an explicit model binding, never a silent fallback or a claim that quantized outputs equal float32 outputs. The same complete semantic/nonnumeric output expectations and270s budget apply.

The CPU int8 kernel is also an explicit optional quantization_engine binding (qnnpack/onednn/x86/fbgemm); omission preserves the runtime default. The built-in3B CPU profile selects qnnpack. Unsupported selected kernels fail with retained diagnostic metadata; there is no silent engine/provider/precision fallback. Kernel choice is captured with the actual quantized module observation. After in-place packing, release unused float-weight setup arenas before allocating generation workspaces.

The standalone Thinker generation call explicitly uses the selected checkpoint tokenizer's eos_token_id and pad_token_id; its minimal generation_config.json must not suppress end-of-turn stopping. Capture those actual IDs. A complete single finding object may be wrapped into findings=[that object] at the existing new-output admission, preserving all model judgments/fields. Do not fabricate findings from unrelated prose/objects. Actual generated token IDs and completion status survive a diagnostic timeout in the same private context; this is observation of the existing synchronous call, not another model stage or a product streaming requirement.

The managed comparison instruction follows the ordered audio parts in the local checkpoint chat template; the adapter supplies the upstream multimodal system identity and captures its exact rendered bytes. The first part is the mutated target and an optional second part is the clean reference. Supported means the intended feature is actually audible; contradicted means it is not realized, with uncertain/not_applicable preserved. Plain transcription is not a diagnostic finding. Successful returned wire stores complete actual generate kwargs/tensors once; input metadata references that captured call rather than duplicating it. Interrupted calls retain the last exact capture and observed token-progress sidecar. This reduces evidence copying without dropping actual context or extending the synchronous deadline.

The optional repetition_penalty is an explicit frozen local decoder setting. Omission keeps1.0; the built-in3B CPU binding selects1.1 to discourage degenerate repeated fragments. Capture its actual generate value. The full findings/description/reason and no-invented-numeric-grade requirements remain, with no timeout or output-budget relaxation.

Project only requested unit/feature pairs into the saved associated measurement rows. Preserve extra model commentary/findings in the original output and wire; an auxiliary unrequested finding does not invalidate a valid requested comparison. It cannot acquire a different target or count as an observed requested finding. Missing requested pairs retain the existing native unknown rows. No response-repair call or new model check is introduced.

The existing tolerant admission accepts a bare complete findings array or a single finding as well as the object wrapper. If a finding omits only its display description, copy its supplied reason verbatim; do not invent linguistic content. Preserve multiple/conflicting model judgments as separate advisory rows and in the complete raw output, without choosing a preferred verdict or changing primary scores. A transcription string does not become an acoustic finding.

Auditory context explicitly separates text scope codepoints from24000-Hz sample positions and supplies native clip_duration_seconds. The managed instruction judges the mutated target only, uses the clean reference for comparison and asks one verdict per requested pair without inferred metadata timestamps. Raw conflicts are still retained rather than resolved in runtime. Development quality qualification separately compares actual generated pause-present and no-pause recordings against independently known presence/absence; merely receiving a nonempty typed finding cannot establish contrast accuracy. These tests do not become ordinary-use gates or calibrated native scores.

The model-visible context projects complete selected realization/controller intent, spoken/canonical context, exact text scopes, sample window and actual duration. Answer correction options, rationale-scoring propositions, display-only accepted_reference and unrelated identifiers remain in the full frozen native input and are not acoustic observations. Equal IPA strings on a temporal-only target are irrelevant to that temporal contrast and are not sent as a phoneme task. All actual controller operands (including explicit zero values) remain. With no controller plan, the typed unit realization still supplies its intended sound and generic requested feature; no scoring rubric or equal temporal IPA is turned into an observed phone. The wire still captures the complete actual model template/IDs/tensors; this projection never deletes case data or changes answer-checking context.


The local Thinker requests supported SDPA attention for both audio encoding and text decoding. Capture the actual text/audio attention implementations; this is the selected algorithm, not a retry fallback. The explicit upstream multimodal system identity is an adapter-owned trusted fragment visible in the captured template. New-output normalization removes only the exact redundant explanatory decorations of the four declared status labels. Ambiguous status prose is never resolved into a judgment; the original visible model text remains intact.

For generic speech_realization on a temporal_fluency unit without an explicit controller/prosody feature, the model-visible projection explicitly asks about the intended pause/pace rather than word presence. This question adds no observed value or expected verdict; controlled-feature inputs remain unchanged. Development Lab export/readback accepts both successful and failed actual observations: a model-quality failure must remain available for debugging and does not prevent artifact/trace verification. Quality qualification remains a separate independently expected case and is not made green by a successful export.

The normalized response and saved auditory_finding allow additional model annotations. Preserve them as model inference data along with the complete raw output. They do not acquire native numeric grades, calibrated confidence, native evidence or a new target. Required canonical judgment and coordinate fields keep their existing meaning; ambiguous statuses still fail the single new-result admission. Extra model commentary alone cannot reject an otherwise usable associated finding.

Model-owned auditory_finding data is opaque to native reference discovery. Identifiers in its annotations are preserved as model-local strings and cannot become database/object links or native acoustic evidence. The containing measurement/run retains actual case and evidence associations. Schema admission still checks the known finding fields once; no annotation reference scan runs on admitted model data.

Settings displays the actually saved audio-judge profile even when its ID is custom. A saved override of a built-in ID displays the actual selected model/billing binding rather than the preset label. Local setup instructions select weights from the actual saved model, not the profile nickname. Refresh/reload preserves that selection; explicit No audio judge selected saves null without changing text-LLM profiles or running inference. These are presentation/selection rules over accepted configuration, not additional validation or a quality gate.

The Gemini HTTP transport honors the explicitly configured standard proxy environment and preserves TLS certificate verification and its existing no-redirect handler. Proxy configuration and credentials are absent from prompt/context/Lab payloads. A proxy changes transport only; it cannot qualify model accuracy or establish a free entitlement. For the free-only setup, admit the selected unbilled project once and trust that configuration for the operation; no recurring account audit is added.
