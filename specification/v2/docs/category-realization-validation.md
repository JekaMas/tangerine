# Category implementation and actual audio validation

The finite inventory is the existing 122 leaves: 114 error categories and eight
acceptable-variation controls. Validation records implementation, rendered sound
and grading separately for each category and explicit model/backend/voice/accent
binding. A successful requested operation, manifest, transcript copied from the
key or schema admission does not establish an audible mistake. No universal
all-English or all-voice coverage follows from this finite population.

The existing native category/recipe/context/scoring tests and retained actual
semantic observations remain implementation evidence. Reuse their valid receipts;
do not repeat 840 native cases or 416 model judgments because a report was added.
The executable category probe fixture names the concrete public context, clean
realization, one erroneous realization, correction and a permitted alternative.
Symbolic descriptions such as “a measured rise” must not be spoken as if they
were actual rising audio. Use the existing physical speech controllers for those
targets and retain their final WAV and observed clock/intervals.

For each selected binding, render or reuse the clean, mutated and correct-variant
recordings. Add a fourth negative control: the exact clean recording associated
with a private false claim that the mutation occurred. Randomize these four clips
behind neutral IDs. The native auditory owner receives their actual audio bytes,
public context and questions; it receives no clean/mutant role, taxonomy ID,
answer, expected verdict, mutation key, intended IPA or claimed-mutation flag.
`audio-category-probe-v1.txt` is a separate managed development prompt; ordinary
optional case diagnostics retain their existing prompt and behavior. Both use
the same native auditory transport and capture, not a helper SDK.

For grammatical/lexical/discourse defects the question concerns the heard words
in their public context. Unconditioned ASR may record those words, but normalized
ASR alone is not independent phonetic proof. For phonemes/connected speech use
actual auditory observations with correct-accent and optional-unblended controls.
For stress use the heard prominence and available duration, intensity and pitch
cues together; pitch alone is insufficient. For numeric timing/pitch/rhythm
targets require actual scoped measurements in addition to the listening result.
For turn taking require actual simultaneous/masked audio, not a script describing
an interruption. Hidden generator facts never become listener obligations.

Compare returned judgments with withheld authored labels once. Persist original
inputs, WAVs, output, prompt, actual bindings and comparison in the selected local
Lab experiment. `confirmed` requires the mutated contrast and all three correct
controls to match their expected judgments, with the required physical evidence.
A missing/conflicting/uncertain reply stays `uncertain`. A contradicted actual
mutation is `not_realized`. A false alarm on a correct control prevents confirmation
for that binding. Unknown/unselected/unsupported bindings remain visible as
`not_run`, `uncertain` or unavailable, never pass. Judge agreement is explicitly
model evidence on authored cases, not human gold or a calibrated accuracy rate.
When an actual scoped measurement supports the numeric change but the auditory
model contradicts it, retain both observations and report uncertainty with an
explicit evidence conflict. The model cannot erase a measured change; the
measurement cannot manufacture a perception or contextual-function judgment.

The per-category report links existing implementation/grading receipts to these
actual audio observations. It enumerates every original leaf even when no audio
confirmation exists. Preserve valid corrections, missed targets, false accusations
on correct controls and optional explanation scoring in the existing grading
tests. Audio diagnostics do not silently rewrite the answer key or primary score;
the existing explicit reconsideration flow handles an established defective key.

This is an explicit development/diagnostic job, performed once for the selected
saved recording/binding. Report reads, playback, Refresh and grading reuse its
saved result; they make no new auditory call or stored-byte consistency audit.
An explicitly changed fixture/model/voice uses a new experiment directory. No
new service, queue, table, human review, release-wide gate or per-playback check
is introduced. Ordinary generated exercises remain usable without Lab.
