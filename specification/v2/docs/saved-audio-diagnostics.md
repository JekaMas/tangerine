# Saved-audio diagnostics and ambiguous expectations

This is QUAL-04's finite development/advisory scope, not another step before
listening or scoring. Use the existing diagnostic transport and saved experiment
owners. No new service, runtime review, database table, schema-byte archive or
per-playback verification is needed.

Both auditory transports use `diagnostic_models.auditory_content` to serialize
the owned projection. Ordinary diagnostics receive public task context, actual
text and selected intended realization/controller targets. Saved corrections,
rationales, learner answers, prior scores and prior observed claims stay outside
that projection. Intended parameters are explicitly intent, never acoustic proof.
Blind probes retain only neutral IDs, public context/questions and actual clips;
their roles, taxonomy, expected labels and mutation key remain withheld. Existing
capture retains the actual serialized request and raw response. Provider or
decoder failures remain failures, without a hidden retry or provider switch.

`make_probe` permits an optional authored `expected_by_role.mutated` override
for an error candidate and an `expectation_note`, both withheld from the model.
Correct clean, acceptable-context and misleading-metadata controls always expect
defect absence. In an acceptable-variant fixture the candidate also expects
defect absence. Copied candidate overrides cannot relabel these correct clips.
Every defect-absent candidate also counts as a correct control for false-alarm
reporting. A judge flagging it yields uncertainty, not a missing realization.
Omission retains the original category/control expectations. An `uncertain` or `not_applicable` expectation
remains uncertain regardless of a model's agreement; it cannot establish a heard
error. Correct controls still require defect-absent judgments. A false alarm,
conflicting/missing/unrecognized judgment or failed observation prevents
confirmation; an unrecognized status is uncertainty, not an unheard mutation.
Keep the actual raw findings. Existing
`not_realized` is a historical model-comparison label meaning that the model did
not confirm the authored target; it does not prove a requested waveform change
was physically absent. Raw findings and original comparisons remain inspectable.

Strong function words are legitimate in emphatic speech and can be legitimate in
careful neutral speech. A preference for reduction does not make the saved full
vowel wrong. A public narrow drill can request a particular realization, but
failure to match that drill is not a universal English error. The saved neutral
weak-form carrier has an explicitly unresolved candidate expectation. Correct
careful and connected forms, assimilation/allophonic variants and declared
accents remain acceptable unless an audible, self-contained communicative context
establishes a specific deviation. Private generator facts never supply it.

Rising statements, falling questions, falling information-seeking wh-questions
and rising confirmation/repetition questions are not inherently incorrect.
Pitch direction is a physical observation; conversational purpose is a separate
judgment using actual public/audible context. Punctuation and requested pitch
points cannot supply either observation. The future selected intonation context
uses the actual words “You have car insurance”; prior requests that omitted
“car” remain original historical records. A changed question/context is an
unperformed new input until its own explicit permitted observation exists.

For the retained pause, PCM comparison establishes 14400 inserted zero samples
at24kHz (600ms), with the surrounding signal preserved outside the existing
120-sample splice fades. The saved decoder proposes its article/noun location;
sample arithmetic does not independently certify word alignment or whether a
listener perceives disruption. A model failing to hear the pause cannot erase
it. Retained native F0 windows establish the selected reference fall/candidate
rise and legitimate question controls; they cannot prove pragmatic error or
override an actual contrary reply. Do not change a correct renderer solely to
obtain a favorable judge response.

The selected research retains all five sets, twenty role-labelled original clip
bindings, actual model contexts/replies and the three unresolved issues: neutral
weak-form appropriateness, perceived boundary disruption, and intonation-function
judgments including the valid-question false alarm. Narrow linking/voiced-joining
successes keep their original voice/context scope. Reconciliation/export/playback
dispatch no inference or synthesis, and never repair a learner key or score.
The existing explicit reconsideration flow owns an established key defect.
Future changed-input functional observations, if requested, use a separate frozen
experiment, retain contrary results and stop without retrying until favorable.

The saved listening sheet labels the altered clip “Candidate recording”; intent
is not heard correctness. Original model context, valid alternative context and
current research conclusions are distinguishable. A missing, partial or unreadable
saved comparison cannot remove independently playable clips or other observations.
The existing file-read owner logs a failed display projection, retries once and
then gives local human guidance with an enabled Refresh action. Refresh only
reads saved results; it must not repeat a model call or synthesis. A failed clip
similarly gets one local load retry and human guidance, while other clips remain
usable. Once the file is available, Refresh restores the observation/player.
Admitted selection and media are reused without repeated consistency checks.

Verification inspects actual saved-audio playback and player switching, keyboard
activation/visible focus, recovery without raw backend errors, readable loaded
typography and narrow layouts. Retain screenshots, an actual screen recording
and original WAV evidence. A rendered player, build or image count alone does not
establish those interactions or acoustic correctness.
