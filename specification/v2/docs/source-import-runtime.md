# Complete local source imports

Iteration13 implements the existing source contracts through a separated deterministic Go source package and application persistence/HTTP owners. The optional Sources screen supports every original source identity. Missing sources never affect startup or the on-demand clean text → mutations → speech → listening → answer → LLM interpretation → exact score flow. No LLM is needed to parse/import data, and no source content/script/formula is executed.

## Intake and scope

POST /api/v1/source-files?name=<relative POSIX path> accepts one ordinary file; archive=true expands ZIP/TAR/TAR.GZ as inert members through the same private storage owner. A directory is the complete set of separately uploaded relative paths. The original archive is retained too. The reply supplies actual paths, byte counts, SHA256 and private asset IDs. Reject traversal, absolute paths, links/devices and duplicate normalized member paths. Configured capacity failure is explicit, never a truncated full import. Every ordinary member, including code, notices, hidden workbook sheets and documentation, remains in the selected release manifest.

POST source-releases freezes source-release-request plus additive scope_kind (full_named_release, partial_export, analysis_companion or mirror; omitted historical value means partial_export) and component_expectations. Each component has actual documented member_globs, expected file count or null, and reconciliation_reason for source count drift. All bytes must already exist in source intake; compare submitted metadata with the accepted receipt rather than re-reading/re-hashing its blob. Native record/annotation counts are separately observed, never inferred from archive/file totals. Components, source partitions and original names remain exact.

All eleven cards are separate: TET-GOLD-1, SPEECHOCEAN762, L2-ARCTIC, WILOCNESS-2.1, FCE-2.1, EFCAMDAT-R2, EFCAMDAT-SHATZ2020, EFCAMDAT-OKSUZ2025, DOUBAO-STUDY-RECORDS, MOODRICK-DATA and NIR-DATA. A companion/mirror/personal export can be retained and used with its actual scope; it cannot receive original-full-source status. External private bytes/dictionaries remain operator/source-owner inputs. ICNALE audio/video is not requested or downloaded.

## Native rows and conversion

The source package owns inert archive inspection, streaming native parsing, documented native presets, exact scalar/offset conversion and deterministic mapping. JSON trees retain original number lexemes, ordered fields and unknown values; CSV/TSV retain headers including duplicates and ordered cells; XML retains expanded names, ordered children, attributes and mixed text/tails without external resolution; XLSX retains all selected sheets including hidden cells, formula text and cached values without evaluation. M2 keeps all annotators, noops, alternatives and source token/codepoint clocks; TextGrid keeps long/short syntax, escaped strings, tiers and exact source seconds; Kaldi locators remain inert strings.

Public native presets follow the source-specific documents. BEA .json files are actually JSON-lines essays; M2 and essay representations are retained separately, with possible duplicate/overlap grouping rather than added unique-population claims. Withheld W&I test labels remain absent. Corrected views use a single non-overlapping annotator's edit set; ambiguous sets remain explicit. SpeechOcean retains aggregate/individual scores and actual five-rater details/scales separately; source text/speaker/audio links must be exact, and arbitrary wav.scp commands never run. L2 distinguishes manual annotation and automatic alignment, retains source44.1kHz clocks and unknown tiers, and preserves observed/published count differences. EFCAMDAT's documented original XML projection retains selection content while separating correction suggestions; unavailable actual private formats require their supplied dictionary/binding.

source-format-binding supports its existing exact fields and optional mapping_program submission or existing binding_program_asset_id. Its programme must match actual source/release/raw manifest. Exact joins, required/null rules, repeated arrays and conversions follow full-build-contract.md. No private header names or narrow122-leaf judgments are guessed. Unbound required semantics remain raw_only; original fields are always recoverable from raw records and full source bytes. /case_candidate is optional, retains source origin and cannot imply machine/human review or a newly playable exercise. Parsed/normalized source records are optional enrichment inputs; no automatic corpus pregeneration or promotion to scoring gold occurs.

## Durable preview, commit and resume

POST /api/v1/source-releases/{id}:preview uses import-request and a fresh Idempotency-Key; it stages and maps native rows in the real PostgreSQL/private MinIO owners and returns import-report. POST the existing :import action selects/commits that admitted result without parsing it again. format_binding_id native selects only documented native source presets; raw-only selects lossless intake without invented semantic mapping. Other IDs select the exact saved binding. A changed binding creates another run; interrupted work reuses its frozen release/binding/parser and stable native row locators. No queue, daemon or human review is introduced.

Import row counts are parser-row units across named tables, not unique learners, utterances, stimuli or empirical exposure denominators. Exact per-table/member counts remain available with raw/corpus/projection records. For each encountered unit observed=accepted+quarantined+rejected; raw_only is a subset of accepted. Scripts/docs/media have file dispositions independent of textual rows. raw_complete reports actual required supplied bytes; normalized_complete additionally requires bound required semantics and truthful component reconciliation. Full original-source status also requires full_named_release and its native/component obligations. No completion flag supplies missing corpus bytes or linguistic truth.

GET /api/v1/imports/{id} reads the report; /progress returns the safe checkpoint; /records and /issues page complete saved rows/findings without running work. X-Tangerine-Revision and X-Tangerine-Import-Cursor expose saved progress; supplied If-Match/continue_after_record reject stale/foreign state. Explicit :cancel preserves accepted partial data and ends the writer; a new explicit :import/preview can resume. Foreground270-second ownership prevents concurrent or late publication; completed action replay uses its own immutable receipt. Process/request failures preserve source bytes and saved rows. Stored reads/resume trust their accepted schema/hash admission.

Source bytes download through GET /api/v1/sources/assets/{id}/bytes as attachments with application/octet-stream and sandbox; they never render as executable HTML. All transport remains existing localhost/private API, without application accounts.

## Terms and documented remote exports

POST /permissions retains real source notices and explicit uses; no human attester is needed. A permitted notice requires its actual documentation asset. Revocation records its actual notice; SourceUse evaluates only the explicitly selected consumer use, with real source/release/expiry and revocation. Missing terms permit lossless intake but grant no derivative, distribution, voice, model-training or external-transfer use. A scalar source score never supplies a perceived phoneme; a source-profile ID never supplies permissions.

PUT /connectors/{id} retains connector-request, optionally the documented remote_spec. It names exact HTTPS endpoint/method, headers/query/body, cursor field/location/initial value, records/next/end/total JSON pointers, explicit completion semantics, dataset version/count unit and auth header/prefix. allowed_hosts constrain the saved adapter. An optional credential_value is written only to the private source credential store and removed before configuration persistence/readback; credential_ref can reference only this connector's own source secret. It is never sent to an LLM or browser export. No endpoint/schema is guessed from a vendor product page.

POST /connectors/{id}:fetch retains every actual original response and its explicitly selected record view. Save each complete page/cursor before continuing; resume uses frozen configuration and last saved cursor. Retry only connection/408/429/502/503/504 once within the remaining deadline, honoring Retry-After. No redirects with credentials. Repeated cursor, missing declared EOF, changed total or final count mismatch remains incomplete. Completed fetch reuses retained pages. Missing adapter reports interface_missing and the local-export alternative; missing secret reports credentials_missing. These are optional exact source adapters, not an additional public API or application authentication service.

## Concrete runtime additions and review clarifications

The Sources screen also configures a documented remote export and fetches/resumes it, without leaving the local app. Its JSON editor supplies the exact remote_spec fields above; an optional record_identity_pointer declares a native scalar identity. Different typed values remain distinct; repeated identical or conflicting identities retain all original pages/records and report the conflict. A corrected configuration starts another export. Connector PUT returns source-status and ETag revision; subsequent saves use If-Match. Credentials use private versioned files so a stale update cannot replace the current secret. The browser stores only connector id/revision and nonsecret adapter settings. Blank credential input with credential_ref:null clears the credential selection when saving a new configuration.

New source intake observes WAVE format/rate/channels/frames once and retains those facts. L2 interval admission compares exact source seconds with that actual recording clock and frame count; neither automatic alignment nor unknown acoustic observations become manual error evidence. Nested ZIP/TAR inputs preserve the original containers and qualified nested member paths, with cumulative capacity and depth8 limits. Native file checkpoint ordering uses the same byte ordering in PostgreSQL and the parser; locale collation cannot omit A/ABC native views. Full-scope counts match complete path components, so N.dev never counts ABCN.dev rows.

XLSX now uses one record-streaming owner for both Parse and Walk. Each row retains its entire ordered native XML tree, including unfamiliar attributes/children, alongside typed cells, formulas and caches. Declared UTF16 is decoded incrementally with explicit malformed-surrogate/odd-byte errors; invalid UTF8 is rejected at new-input admission. Neither requires reading an entire text export into memory. A restarted import reuses admitted rows; native input row decoding is not a stored-data integrity audit.

Each saved row includes a transformation2.0.0 parse record: the frozen parser/mapping method hash, original input asset/hash, actual foreground operation receipt, selected permissions and completion time. In-database rows have empty output-asset/hash arrays; no nonexistent output blob is invented. Its corpus record remains version1.0.0 and links that actual transformation. Optional case_candidate retains its own1.0.0 contract. A documented EFCAMDAT learner_id mapping shares the original learner namespace across derivatives; unrelated vendors stay distinct.

For an actual TET-GOLD import, a mapping may project raw_metadata.gold containing a complete ground_truth2.0.0, pair_id, pair_role (positive/control), split, genuine group_ids and actual label_origin (source_import/llm). Admit the supplied key once. The full-source accounting owner requires732distinct playable audio/context/key conditions, all122leaves/eight domains, at least six distinct conditions per leaf across three paired split families, and no connected group across splits. Local identifier aliases are not distinct stimuli. This counts actual supplied metadata and available accepted recordings; it does not generate a bank, certify semantic correctness or call a model. Constructed accounting tests are labelled separately from any acquired/generated gold release.

Issue cursors serialize the actual locator/code tuple; their SQL ordering and continuation predicate agree. The report includes the first1000issues and, when needed, a full private issue JSONL asset. Historical failed operations remain visible; successful explicit recovery is assessed from saved row dispositions and real native parse findings, rather than being permanently poisoned by an earlier timeout. A currently failed operation cannot report normalized completion.

The existing input API remains unchanged. Additive runtime operations are: POST source-files (201member list), POST source-releases (201source-release), GET source-releases/{id}, POST source-formats (201source-format-binding), POST permissions (201grant), POST permissions/{id}:revoke (200permission/state), GET sources (source-status list), POST source-releases/{id}:preview/:import (200import-report), GET imports/{id} (import-report), GET imports/{id}/progress (report/revision/phase/member_cursor/row_cursor/format_binding_id), GET imports/{id}/records (items plus next_cursor), GET imports/{id}/issues (items plus next_cursor), POST imports/{id}:cancel (200import-report), GET sources/assets/{id}/bytes (attachment), PUT connectors/{id} (200source-status plus ETag), POST connectors/{id}:fetch (200files/pages/observed_records/expected_records/complete/conflicts). Error bodies contain error; malformed new input is400, capacity413, stale/concurrent action409, missing saved identity404, dependency failure503. Import failure includes X-Tangerine-Import-ID so the UI can retain and display its saved checkpoint. No endpoint implies a public multiuser service or new authentication system.

Mapped rows commit in batches of64 through the dedicated projection-storage owner, with one foreground ownership check per transaction. A failed batch rolls back its rows; retry uses earlier admitted batches and stages. Progress counts follow committed writes in memory and final/readback counts come from stored rows, without repeated full-table recounts after every batch. Immutable binding and source-notice admissions reuse the exact existing content envelope; unchanged connector saves reuse their accepted revision/export. Changed selections remain distinct, and changed permission IDs cannot silently replace a frozen import context. Missing media bytes return dependency failure before an attachment success response.

Native TextGrid parsing consumes the already decoded text and does not run the encoding conversion again. Legacy field bindings respect the parser's duplicate-key finding; conflicting semantic keys stay quarantined with their complete original tree. Native essay group identities include their dataset namespace, while genuine same-source IDs stay linked across releases. Storage read/close errors remain failed dependency operations, separate from permanent native parse findings; restoring the accepted object allows explicit resume without a new raw hash or schema audit.

### Full-release traversal and current count diagnostics

Projection advances through staged rows in `(member, table_name, ordinal)` order
using a per-call keyset after each saved/checkpointed batch. It must not repeatedly
scan an expanding accepted prefix. Reopen starts from durable row states;
accepted rows are not parsed or admitted again and no new durable-cursor gate is
required. Current count findings report current named units and numeric expected
values. Resolved count discrepancies remain in history, not active findings;
a remaining discrepancy reports its latest actual population.
