These are optional supplemental sources through the existing lossless directory/archive/export intake. They add data, reference answers and context; they do not create source labels for every Tangerine taxonomy leaf. No new public API, account system, approval ceremony or source-wide gate precedes ordinary local use.

Keep release/commit, exact file bytes, native field names, source partitions, alternate representations, source terms and documentation. Report native raw acquisition separately from semantic normalization and implemented importer/evaluator acceptance. Code and bundled tools remain inert. Unknown source meanings remain raw_only. Each supplemental source has a separate identity; deduplicate logical records only using documented source identifiers and compatible versions, retaining every representation. Do not add combined and component partition counts or original and edited versions as extra independent stimuli. ## Native supplemental conversion meanings

JFLEG raw source IDs are partition plus native line index. Keep all four correction texts as acceptable reference alternatives. Written corrected text can support future contextual LLM judgment and answer-matching examples, but applying a writing repair does not prove that its corresponding audio contains an audible target mutation. Derive source edit spans only against the unchanged native text using a separately recorded alignment method; ambiguous alignments stay explicit rather than becoming invented source annotations.

ELRD preserves complete dialogue identity, original audio and source JSONL turns. A source turn/speaker tag is a source identifier, not a teacher answer or a phonetic diagnosis. Keep ASR origin; retain pauses, repairs and uncertain text when present. Normalized teacher-error units require context-supported LLM mapping and actual final-audio evidence, as already defined for all sources.

DiPlomat stores every native task record and exact fields. First-PIR correct_turn_number locates a source conversational turn; second-PIR choice/label retains the source pragmatic class and answer choice. CQA questions/answer/gold_statement are native alternatives and statements, not universal repair strings. NLI hypotheses or human answer fields keep their original source meaning. Preserve context and speaker orientation; do not count overlapping task views as unique conversations or use source split answers as unseen evaluation gold after generation has consumed them.

EdAcc retains audio/channel/session/speaker metadata, STM/transcript clocks, alignments and README/license. Source clocks and dialogue identity remain authoritative; normalize without deleting raw speech fillers. Variety metadata creates a contextual reference/control. A different lawful English accent never becomes an error merely because it differs from a selected reference voice.

DRAL retains original conversations, recording sessions, matched-pair identities, language, prosody/intent annotations actually supplied, documentation and version additions. Cross-language or re-enacted pairs are aligned source examples, not minimal learner-error edits. Preserve source roles and acoustic timing; only a source-provided or context-supported label can become a candidate taxonomy unit.

ICNALE keeps every original/edited, classified/unclassified, merged/POS-tagged representation, workbook sheet and rating dimension. Individual/unmerged IDs and filename fields (module, region, task, student, CEFR, original/edited) determine source identity. Merged/category views are overlapping representations. Background survey values remain source data and are excluded from ordinary LLM prompts. Keep exact source rating rubrics, scales and formulas; do not replace them with Tangerine grades. Audio/video URLs are dependency locators, not locally acquired assets. The old 2019 information-sheet URL returned404; the current202603 survey is acquired. GRA video examples are separate links, not included audio bytes.

## Current implications for mutation, diagnosis, answer matching and accents

Full public writing releases plus JFLEG improve coverage for alternative valid repairs. SpeechOcean supplies real sentence/word/phone scores; L2-ARCTIC has a complete pinned raw mirror, with official identity and native operation-count discrepancies recorded in l2-arctic-v5.md. ELRD/DiPlomat/DRAL/ICNALE add authentic conversational or pragmatic context where available. None proves a complete leaf-by-leaf empirical dataset, every acoustic mutation recipe, or correct diagnosis of every generated mistake. Original project-gold stimuli/teacher answers and actual per-leaf coverage remain to be produced and evaluated by the specified LLM workflows.

These corpora also do not solve accent synthesis. EdAcc/ICNALE/L2-ARCTIC recordings are examples, not automatically licensed voice clones or TTS checkpoints. AccentBox's linked GenAID project is accent identification, not a verified generation checkpoint. The active voice configuration still supports its explicitly specified provider/accent values; extra synthesis accents need a concrete configurable provider/voice binding and observed final audio. Preserve all original target varieties; never equate an unsupported synthesis voice with impossible source intake or reduce the source collection.
