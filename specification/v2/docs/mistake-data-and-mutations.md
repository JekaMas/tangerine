# Mistake data, relationships, frequencies and mutation use

This contract owns the connection between taxonomy, native data, generation and answer checking. The exact 122-entry catalogue is domain/mutation-recipes.v1.json. Its examples are authored design examples, not external corpus observations or verified final audio. The current acquisition observations and per-leaf data audit are in audit/mistake-data-coverage-20261009/. This document specifies future behavior; no importer, generation or scoring implementation was performed for this audit. simple-generation-flow.md owns the latest primary flow: the app creates text/mutations/audio and compares listener answers with the saved mutation key. Existing source/benchmark data are optional enrichment/evaluation inputs, not prerequisites.

## Scope and completeness

The project taxonomy has 114 error leaves and eight acceptable-variant/control leaves across eight reporting domains. It is a finite training taxonomy, not an exhaustive enumeration of every possible English mistake, communicative context, accent or combination. New phenomena retain their original data and explicit unmapped status until an intentional taxonomy version extends the catalogue. Never force an unknown phenomenon into a convenient existing leaf to claim completeness.

For each leaf, report definition, inclusion/exclusion criteria, authored example, mutation recipe, candidate sources, localized native evidence, LLM conversion evidence, observed final stimuli, controls, split identities and frequency population separately. A definition or one authored pair cannot fill a source-example or benchmark count. Downloading a complete source does not establish that it covers every requested leaf. Missing measurements are null with a reason. Zero is reserved for an actually enumerated population with zero occurrences.

All eleven original sources and their complete scopes remain required features. Supplemental sources do not replace them. Raw source labels, unknown labels, written-only annotations, alternatives and controls remain accessible even when ineligible for listening exercises. Ordinary local generation/use does not wait for the full 732-stimulus benchmark or the complete source collection. No human peer review, new account system or corpus-wide certification is introduced.

## Relationships

Each dotted taxonomy path has explicit parent/child edges in the catalogue. These structural edges support existing hierarchical classification credit. They are category organization, not a measured causal relationship. Reporting domains remain exactly the original eight domains, including pronunciation.segmental and pronunciation.suprasegmental.

Three further relationships have distinct meanings:

1. Alternative labels on one event: accepted/secondary taxonomy IDs in the existing planned/key unit. One independent repair obligation contributes one detection opportunity regardless of how many labels describe it. Fixing either of two independent obligations while leaving the other defect establishes two units, even at a shared span.
2. Co-occurrence: two independently localized events occur within a declared sentence, utterance, dialogue or exercise. Report window, source, partition, annotator, event identities and actual denominator. This association does not imply that one error causes another. A label pair on the same event is not co-occurrence of two errors.
3. Confusability: a particular mapper's observed predicted category differs from its frozen reference category for a declared evaluation population. Retain model/prompt/key versions and the confusion matrix. Taxonomy similarity, an LLM suggestion or a native label pair is not an observed confusion result.

Known potential overlaps are explicitly recorded as candidate analysis relationships in the catalogue. They guide contextual judgment without granting category credit or inventing empirical frequencies. Examples include irregular verb form versus tense, noun number versus an audible final plural segment, lexical register versus context formality, and weak form versus vowel reduction. The case key chooses the most specific supported analysis and retains other valid analyses. There is no measured all-leaf co-occurrence or confusion matrix yet.

## Frequency population and arithmetic

Use a named source release and view, split, annotator policy, window, modality, taxonomy/mapping version and any actually available L1/CEFR/task metadata. Unknown learner metadata stay unknown. Do not extrapolate a writing frequency to speech or a learner population to all English speakers. Do not pool native and LLM-inferred labels without separate origin strata.

These are descriptive source statistics, not changes to the 27 core or 15 auxiliary scoring equations:

- Event share for category t: n(t)/sum_u n(u), for the same declared eligible event population. Secondary labels are reported separately; a multi-label view explicitly states that shares need not sum to one.
- Window prevalence: number of fully inspected eligible windows containing t / number of fully inspected eligible windows. A sentence with three occurrences contributes one to this numerator.
- Error opportunity rate: erroneous opportunities for t / all inspected opportunities where t could legitimately occur. It is unavailable when correct-opportunity annotations are absent. A sentence count or a token count is not this denominator.
- Events per 1,000 tokens: 1000*n(t)/T, where T is the unchanged native token count for the same selected view. This is exposure density, not probability of making an error.
- Pair prevalence: number of windows containing distinct t and u events / inspected windows. Conditional co-occurrence is that pair count / windows containing t. A zero conditioning denominator is unavailable. Same-label pair counts require at least two independent events, not just presence.
- Confusion row proportion: observed reference-t/predicted-u decisions / all eligible reference-t decisions, with abstentions/unknowns included as separate predicted columns. No observed decisions means unavailable.

Store numerator, denominator and exact rational separately; display rounding does not replace those counts. The denominator is available only when the corresponding population has actually been inspected. For broad native labels, these formulas remain native-label statistics until a contextual conversion has produced localized project events. LLM synthetic sampling frequencies are generator configuration, not learner prevalence.

The current BEA audit counts every native M2 tag separately by source/split and annotator view. Its selected descriptive view chooses the lowest integer annotator ID present for each S-block, excludes noop and unresolved UNK/Um from corrected-event shares, retains their counts separately and preserves writing-only SPELL/ORTH/PUNCT. It reports presence and tag-pair co-occurrence per S-block. A native edit is not automatically one Tangerine communicative event. Aggregate/component representations are inspected separately and never added together. W&I test has no public labels; its error frequency is unavailable. These native observations cannot fill any of the 122 inferred leaf frequencies.

## Text and contextual mutation recipes

Choose target leaves/counts, variety, task, speakers and explicit context from the blueprint. The LLM first writes a coherent canonical script. It then selects a leaf's recipe and an opportunity that satisfies that leaf's inclusion criteria and none of its exclusions. Source-derived opportunities refer to an actual source record/excerpt and retain its notice; authored opportunities are labelled authored. Do not invent quotations or participant records.

For each intended edit, record the existing utterance/unit ID, canonical substring and half-open codepoint span, exact replacement, intended surface substring/span, primary and alternative labels and the repair obligation. These values are the generation provenance for existing canonical_text/surface_text, text_spans, realization and correction fields; the catalogue is static configuration, not a new service or public API. Use the existing source/evidence provenance asset path for a lossless edit ledger rather than adding arbitrary fields to closed record schemas.

The server selects actual recipe records into generation-input.mutation_recipes with recipe_registry_sha256, under generation-contract-details.md. type=mutation evidence references the exact typed mutation-manifest.schema.json asset; its fields, JCS candidate hashes, edit coordinates/replay and acoustic intents have one authoritative projection there. Keep request/manifest digests with actual private receipts. The older custom provenance payload is superseded, without losing original recipe/examples/source data. Planned provenance is distinct from observed-phone/prosody/alignment evidence.

The single-replacement design example algorithm is precise: find the longest common codepoint prefix of canonical and surface strings; then the longest common suffix of the remaining strings. The unmatched canonical interval is the replace/delete/insert opportunity, and the unmatched surface interval is the mutation. Empty old/new intervals mean insertion/deletion. No Unicode normalization changes source offsets. This algorithm locates an authored example's difference; it is not a linguistic category classifier or a guarantee of a minimal semantic repair.

For a new candidate with several edits, compose explicit edits against the same canonical version from right to left. Disjoint edits preserve every outside substring. Overlapping edits require one explicit composite transformation; equal-offset insertions require an explicit order. Never apply stale offsets to an already changed string. The LLM may rewrite a larger clause when the meaning needs it, but the larger replacement and all new obligations must remain explicit. Mutation generation supplies the contextual list/key for ordinary use. Optional case review or a later answer dispute can identify accidental additional defects and update the key rather than silently changing the original mutation version.

For native corrections, first reconstruct one compatible annotator's corrected text under docs/sources/bea-v21.md. The source error-to-correction direction is reversed only after the corrected text and target context are established: corrected canonical -> original erroneous span. Preserve token/codepoint alignment and source annotator. Several acceptable references are alternatives, not simultaneous mutations. An ambiguous native reconstruction remains raw data and does not silently become an injectible pair.

All original taxonomy illustrations remain unchanged. The catalogue supplies concrete supplementary contexts for abstract discourse/variant illustrations. It also corrects the auxiliary illustration's misleading “Progressive past form” context: “They were went home” -> “They went home” demonstrates a completed simple-past auxiliary defect, not progressive meaning. The original across illustration changes final /s/ to /sts/, adding two segments; the supplemental single-insertion recipe uses /s/ -> /st/. The intonation-function illustration's reference to two contextual reviewers describes an old illustration, not the current review workflow; its recipe uses the actual configured audio-capable LLM. These clarifications do not constitute acquired linguistic gold.

Discourse/pragmatic recipes retain all turns, facts, speaker roles, relationship, communicative goal, intended speech act, register and permitted varieties required to diagnose the event. Change the particular reference, connector, order, relevance, commitment or register specified by the leaf; do not manufacture an error by hiding decisive context. A source record without enough context is useful source material, but not a verified pragmatic unit.

For the eight acceptable-variant recipes, retain or substitute a permitted variant and set expected_judgment=acceptable. No correction is required. Controls are not erroneous mutations and do not increase the true-error denominator. Written punctuation/spelling edits are preserved as written data; they are not automatically listening errors.

## Acoustic and temporal recipes

Keep the intended word/text separate from pronunciation. Segmental recipes specify the chosen variety, canonical/intended IPA or other exact target contrast, target word and actual final interval. The existing render-plan phoneme operation submits intended IPA without respelling the transcript. Phone substitutions/deletions/insertions can be requested this way; phonetic timing, aspiration, voicing, articulatory manner and exact acoustic realization are not guaranteed merely by an IPA string. For these targets, the recipe states the required final evidence and permits a suitable real source/local recording through the existing import path. A synthetic generation blueprint remains synthetic_only; recording import is a separate lifecycle route, not a fabricated successful synthesis.

Prosodic recipes specify word/syllable/scope, semantic context, requested rate/pitch/contour and the target label or per-item numerical interval with its unit. Apply only the existing typed text/phoneme/prosody/pause operations supported by the selected voice profile. SSML prosody is a request to the provider. It cannot guarantee lexical stress, pragmatic force, connected-speech processes or an exact measured pitch/rhythm interval. Voice availability and final audio establish what happened. No automatic fallback changes the requested target or accent.

Fluency recipes inject literal fillers, repeats, false starts, abandoned turns or conflicting repairs as text; timed pauses use an explicit pause operation at the specified boundary. Speech-rate and density targets include the unchanged denominator and per-item bounds. A requested rate percentage is not measured WPM. A four-second planned pause remains part of the exercise, not a silence defect to trim. Turn interruption can be scripted by truncating the interrupted turn before its critical completion; simultaneous masking requires an actual overlapping recording because the existing sequential turn renderer does not supply an overlap mixer.

Measure the final playback asset with docs/audio-methods.md. Retain sample clocks, transcript/interval alignment, requested and observed values and evidence origin. Native phones labels, actual acoustic measurements and an audio-capable LLM's modality-labelled inference can support diagnosis; ordinary text-only DeepSeek cannot hear a WAV. ASR agreement or low word WER does not establish a phone contrast. A text-only checker can use actual annotations/measurements, while unresolved acoustic facts remain unknown. Machine review and playable-audio quality warnings remain the existing local-use behavior; uncertainty never becomes a fabricated observed IPA or satisfied hard target.

Accent choice uses the configured provider/voice/locale/accent binding. Available corpus recordings give authentic comparison/control material; they do not train or clone an accent by being downloaded. Preserve all requested varieties and source terms. Accent difference alone is not an error. New accent synthesis bindings require an actual supported voice/provider and final audio observation; no complete accent synthesis library is currently evidenced.

## Diagnose and match answers

Freeze the actual case/audio/context/key version before the attempt. The key contains localized events, accepted/secondary categories, acceptable controls, severity, permitted repairs and required/forbidden propositions. The saved mutation list owns the ordinary authored key; optional later review can revise it when an actual audio/text deviation or omitted defect is found. Retain actual final audio even if the provider did something different.

Use the existing single configurable LLM mapper to interpret original free-text answers. Extract assertions with their original Unicode spans, locate the event using quotation/turn/time/description and context, and judge stance, category, repair and explanation against the frozen key. Semantic synonyms and valid novel repairs can earn credit under the existing proposition rubric. Surface string equality or a category keyword does not decide semantic correctness. Wrong category can still detect the right event; absence of localization cannot fan one claim out across repeated words. Duplicate fragments about one event count once; explicit retractions and contradictions follow docs/math-and-judgments.md. Genuine key defects invoke LLM adjudication/versioning, with no human peer review prerequisite.

Example: canonical “She works here.” -> surface “She work here.” gives one subject-verb-agreement event. “The verb after she needs -s; say works” and “Change work to works in the first sentence” can both detect/correct it. “Use worked because it happened yesterday” conflicts with the fixed present context. Two copies of “She work here” in different turns create two occurrences; an unlocalized quote cannot arbitrarily select either or receive both credits. Calling a permitted “Did you eat yet?” wrong under a context permitting that variety is a false assertion on a control.

Native code derives event counts, exact proposition-credit fractions, all existing metrics and the composite. Models do not invent numeric grades. Generated examples, raw corrections, annotation statistics, machine-answer runs and genuine teacher-answer populations stay separate. Difficulty derived from genuine teacher attempts is not supplied by corpus error frequency or synthetic model answers.

## Data for complete source research and benchmarks, not generation prerequisites

1. Localized source record/annotation/interval -> leaf mappings with exact context and mapping provenance for all 122 leaves. Complete written corpora offer candidate material, not already normalized per-leaf coverage.
2. Actual per-leaf final error/control stimuli and retained independent split families for the complete 732-stimulus target. None was created by this audit. Acquired native audio is not itself this benchmark.
3. Acoustic minimal contrasts, final alignment, per-item target parameters and observed evidence for all 14 segmental, 12 suprasegmental and nine fluency leaves. Abstract illustration phrases are not phonetic calibration data.
4. Fully contextual discourse/pragmatic event labels and acceptable variants. DiPlomat, dialogue corpora and ICNALE add useful context, but their labels do not equal all project leaves.
5. Correct-opportunity annotations for opportunity rates; declared-source leaf counts for prevalence; independently localized event pairs for co-occurrence; actual mapper/reference decisions for confusion. No universal learner frequency or causal graph is available.
6. Missing complete Cambridge originals/derivatives/dictionaries, Doubao participant records/instruments, separate Moodrick/NIR exports/terms, ICNALE linked audio/video unavailable under the owner prohibition (sources/icnale.md), Speak & Improve access/data, and official L2 provenance/count reconciliation, as itemized in the acquisition audit. Optional DRAL 48 kHz representations and its unavailable third-party component remain separate scopes.
7. Actual generation/provider, answer-checking and genuine teacher-attempt observations for empirical performance and difficulty. None is implied by this written contract or the raw-byte inspection.

These are full-source acquisition/empirical evaluation work and external inputs; they do not block the main text-to-mutation-to-audio flow, not unresolved requests for product-owner approval of ordinary LLM checking. No new user decision is needed to perform the spec audit.
