# Speech preparation runtime

The iteration25 finite comparison reuses the same native Qwen plan/piece and
foreground child owners. Its optional local development runtime is explicitly
selected with `TANGERINE_QWEN_DEVICE=cpu|mps` and
`TANGERINE_QWEN_DTYPE=float32|float16`; defaults stay CPU/float32. Actual compute,
Torch version, tokenizer/generation input, pinned model and voice are saved in
the existing receipt. Native planned pieces retain `qwen_runtime` with the
selected device/dtype. That frozen selection is consumed by synthesis and wins
over a later server environment; unbound legacy/direct pieces use the explicit
environment/defaults. The comparison CLI carries its selected runtime into
these pieces rather than merely labelling the result. Requested placement and
loaded model/codec placement are separate receipt facts, with unknown values
remaining unknown. An unavailable selected device returns the existing
capability failure and never falls back. This does not select a new ordinary
provider, change the Docker-only application prerequisites or qualify arbitrary
MPS model/voice combinations. The selected CustomVoice comparison still needs
actual complete native/Lab/media observations; respelling is an approximation,
and a short preview remains incomplete. See
`audit/iteration-25-qwen-20261026/README.md` for its exact scope and saved source.

Iteration7 implements rendering of an existing on-demand preparation after its clean text and mutation phases. The foreground Go owner reads the accepted frozen settings and candidate; it never calls the text LLM during rendering. Controlled acoustic operations are implemented by iteration8 as defined in controlled-acoustic-runtime.md; source/native-import integration remains iteration13. Their contracts and features are preserved.

POST /api/v1/preparations/{id}:render accepts preparation_id and a positive render_attempt with Idempotency-Key. The CLI equivalent is `prepare` action `render`. GET /api/v1/preparations?view=public supplies only preparation identity, phase states, availability, safe failure and the next render counter; limit/cursor pagination preserves access to all records. GET /api/v1/preparations/{id}/audio streams the saved finite WAV and supports byte ranges. The browser exposes these operations through its existing private proxy and displays Generate audio, Retry audio and stored playback. Refresh retries failed reads and reloads the audio element. Text, mutations, correction key and private receipts are never returned by this listener view.

The application resolves the selected frozen speech profile and speaker voices. A voice's configured locale is independent of the assessment variety. An accent is a voice request/description, never an error or an inferred acoustic observation. Local Kokoro provides the four packaged US/GB voices; eSpeak provides explicit configured voice IDs; Qwen CustomVoice provides its installed model speakers; Qwen Base uses an explicitly saved reference and clone conditioning. Azure F0 and ElevenLabs use an explicit configured endpoint, model/voice catalogue and permitted account allowance. There is no backend fallback. OpenAI token-billed TTS is unavailable under the current included-only policy. A declaration of an allowance is not a live account qualification receipt.

Model acquisition is an explicit `scripts/tangerine model-setup PROFILE` action in the existing speech container. Supported model setup profiles are kokoro-local-en-v1, qwen-base-v1, qwen-design-v1 and qwen-custom-v1. Complete acquired files and their upstream revision/terms are recorded once in `/models/PROFILE/manifest.json`. Interrupted, unadmitted downloads retain partial bytes and resume using HTTP Range; an accepted file is reused without rehashing. Ordinary startup, planning and inference have offline model access and do not download weights.

`voice-setup` takes JSON on stdin: profile_id, voice_id, mode (design/local_reference), reference_text, locale, and voice_description for design or a model-volume-relative reference_path for a local reference. Design generates the reference with the pinned VoiceDesign model. Both modes normalize the reference, create clone conditioning with the pinned Base model, and save reference.wav, reference.txt, conditioning.pt and their manifest under `/models/voices/PROFILE/VOICE`. Repeating the same request returns the saved voice. Changing its definition requires a new voice ID; it never silently replaces the conditioning of an existing exercise. The model volume is private durable speech storage, not a public MinIO asset; future backup/restore must include it. The native receipt retains its actual manifest and reference origin.

Kokoro's tokenization yields ordered pieces within the installed model's actual phone capacity. Other text adapters split long turns at word boundaries. Each piece retains utterance, speaker, voice, locale and literal mutated text. Only a turn's final piece has the configured inter-turn pause. The first accepted plan and profile are retained privately. Completed child operations and pieces survive interruption; an explicit retry reuses their accepted response/audio without a new provider dispatch. A failed operation's idempotent replay returns its saved failed result. A new attempt resumes missing pieces under the same bindings. Only the final assembly and answer-key association complete the preparation.

Every newly generated provider output is decoded once into finite mono PCM16 24kHz WAV. Assembly concatenates exact accepted samples and exact pauses. The saved sample map drives containing-turn intervals; no character-proportional word timing is invented. The rendered answer key preserves every planned mutation/correction/explanation and records actual audio identity and the frozen taxonomy version. Pronunciation/accent realization remains unknown unless measured; there is no fabricated accent verification or empirical difficulty. Silence, loudness and peak observations are advisory warnings, not publication gates. Ordinary use has no human review, corpus acquisition or Lab dependency.

The foreground request has the existing270-second deadline. Each active private synthesis invocation belongs to its foreground caller; timeout/disconnect kills its process group. Kokoro reuses one private local model process between pieces, retaining the loaded model in memory with up to four CPU inference threads. Successful calls leave it idle; no synthesis runs without an active caller. Calls serialize access to that model; a waiting caller can expire or disconnect without cancelling the current owner. A cancelled, timed-out or exited model process is reaped and recreated lazily for the next call. Other per-invocation workers retain their existing lifetime. Completed pieces remain. Provider/network/setup/audio failures become canonical application failures while their original error code and native context remain private. Exceptions never expose credentials. Each actual dispatch retains its original wire request/response and a native speech context, provider receipt and optional diagnostic/MLflow trace. These are speech inputs, not an invented text-LLM prompt. Local synthesis does not establish hosted account entitlement or perceived accent quality.

Local development capture observes Kokoro’s actual forward_with_tokens inputs and Qwen’s actual framed tokenization and resolved decoder arguments during the original invocation. It preserves sampling parameters and saved reference conditioning without a second inference or runtime approval gate. Speech wire responses retain their original received bytes and actual HTTP status. Independent native test transport observations are reconciled with saved receipts/contexts and MLflow; the native speech inputs are not text-LLM prompts. Accent labels remain requested rather than verified observations.

Normalization owns codec conversion, and the render owner admits its new finite output exactly once. Accepted pieces and stored final audio are reused directly. Reference-voice setup similarly admits a new reference once. Advisory loudness probe failures/timeouts record not_measurable and warnings rather than preventing usable audio. Method/version and the captured runtime build identify the tool; no per-piece executable rehash is performed.

Final advisory measurement transport failures (including unavailable service or unreadable reply) retain quality.state=not_measurable, null measured loudness/peak and quality_unavailable with the safe native error code. They do not withhold accepted audio. Actual foreground cancellation/deadline still interrupts the operation. Assembly is owned by speech_assembly.go; orchestration, SQL/storage, pure sample/pace projections and HTTP transport remain distinct owners.

The private assembly diagnostic retains pace rows in frozen speaker order: speaker_id, target_wpm, tolerance_fraction, observed_wpm, deviation_fraction, state and reason. Without actual timed lexical tokens/onset/offset, observed_wpm and deviation_fraction are null, state=not_measurable and reason=timed_lexical_tokens_unavailable. Written surface/canonical word counts and full-clip duration cannot replace the audio-methods.md lexical-v1 observations; acoustic measurement/controller work remains iteration8. The requested pace is a preference, never a publication gate.
